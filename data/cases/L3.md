## L3-A-01｜线程 A-约束枚举｜物流运筹 → 生态学

共享 mindset：在网络中沿边累积代价、求端到端最优路径；贪心的"最优子路径拼成最优全路径"结构。

### 源题（物流运筹）
某快递网络为有向图，节点 {S, A, B, C, D, T}，边上标注运输时间（小时）：
S→A: 2，S→B: 3，A→C: 2，A→D: 3，B→C: 4，B→D: 2，C→T: 2，D→T: 5，A→T: 7，B→T: 9。
求从 S 到 T 的最短总时间。

解法：Dijkstra——维护每个节点的最短已知距离，每次弹出距离最小的未定节点并松弛其出边。松弛序列给出 dist(A)=2, dist(B)=3, dist(C)=4, dist(D)=5, dist(T)=min(2+7, 4+2, 5+5, 3+9)=6。最短路 S→A→C→T。
答案：6

### 目标题（生态学）
一只候鸟从越冬湿地 S 飞往繁殖地 T，中途可停靠湿地 {A, B, C, D}。每段航程有两个属性 (飞行天数, 消耗脂肪单位)：
S→A: (2, 5)，S→B: (3, 2)，A→C: (2, 5)，A→D: (3, 1)，B→C: (4, 2)，B→D: (2, 6)，C→T: (2, 4)，D→T: (5, 2)，A→T: (7, 3)，B→T: (9, 1)。
该鸟起飞时脂肪储备共 9 个单位，途中无法补充（各停靠点食物已因干旱枯竭，只能休息不能增重）。求在总脂肪消耗不超过 9 的前提下，最少总飞行天数。
答案：9（数值，可行最优路径 S→A→T 或 S→B→C→T，各耗脂肪 8）

### 照搬为什么错、需要怎么改
- 照搬（错误答案 = 6）：直接对"天数"跑 Dijkstra 得 S→A→C→T，总天数 6——但该路径耗脂肪 14 > 9，不可行。
- Model 哪里变了：单代价最短路 → 双准则"约束最短路"（RCSP）：可行域被资源预算切割，最优子结构在单一维度上失效（被支配的高耗能前缀可能不在任何可行解中，低天数前缀可能因耗能出局）。
- Method 需要哪步适配：状态从"节点"扩展为"(节点, 已耗资源)"，在扩展状态图上做标签算法/DP（或按帕累托标签保留非支配 (天数, 能量) 对），最后只在能量 ≤ 9 的标签中取最小天数。

### Lure（生态学表皮、无约束结构）
"另一只候鸟体能充沛（脂肪不设限），在同一张停靠网络上只求最少飞行天数"——纯 Dijkstra 解答。
- 表面相似：同为候鸟迁徙、同一张图、同问最少天数。
- 结构不同：无资源维度，可行域未被切割；照搬其解法到目标题得 6（错误），真值 9。

verified：python3 DFS 枚举全部 6 条简单路径，核对 (天数, 能量) 二元组；无约束最小值 6（能量 14 超支）、预算 9 内最小值 9，断言通过。

## L3-G-01｜线程 G-混合亚群建模｜可靠性工程 → 金融风控

共享 mindset：系统失效 = 多部件联合失效，联合概率由部件失效概率组合而来。

### 源题（可靠性工程）
一套冷却系统装有两台相互独立的冗余水泵，只有两台同年都故障系统才失效。年故障率分别为 p₁ = 0.05、p₂ = 0.08，两泵机械上完全独立（不同厂家、不同供电回路）。求系统年失效概率。

解法：独立事件联合概率 = 边际相乘：P(两台都故障) = 0.05 × 0.08 = 0.004。
答案：0.004

### 目标题（金融风控）
某银行持有两笔贷款。评级表给出的无条件年违约率分别为 7.4% 与 9.6%。已知两家企业的违约都受同一宏观景气状态驱动：
- 景气"良好"（概率 0.7）：两笔贷款的条件违约率分别为 0.02 与 0.03；
- 景气"衰退"（概率 0.3）：条件违约率分别为 0.20 与 0.25；
给定景气状态后两笔违约条件独立。求两笔贷款同年双双违约的概率（小数，保留 5 位）。
答案：0.01542（容差 ±0.0001）

### 照搬为什么错、需要怎么改
- 照搬（错误答案 = 0.0071）：套用"独立→边际相乘"：0.074 × 0.096 = 0.007104，仅为真值的一半不到——共同宏观因子使违约正相关，边际相乘系统性低估尾部联合风险（2008 年 CDO 定价的经典错误）。
- Model 哪里变了：联合分布从"无条件独立"变为"共因潜变量诱导的相依"——独立性只在条件于亚群（景气状态）后成立。
- Method 需要哪步适配：先按潜状态分层，层内条件独立相乘，再对层加权（全概率公式）：P = 0.7×0.02×0.03 + 0.3×0.20×0.25 = 0.00042 + 0.015 = 0.01542。

### Lure（金融表皮、真独立结构）
"两家分处不同国家、行业互不相关的小微借款人，题面明示违约相互独立，违约率 7.4% 与 9.6%，求同时违约概率 = 0.074×0.096 ≈ 0.0071"。
- 表面相似：同为两笔贷款联合违约、同样的边际违约率数字。
- 结构不同：无共同因子，独立性真实成立；照搬其解法到目标题得 0.0071（错误），真值 0.01542。

verified：python3 直接算术核验：边际 0.7×0.02+0.3×0.20=0.074、0.7×0.03+0.3×0.25=0.096 与题面一致；天真乘积 0.0071040、条件化真值 0.0154200，断言通过。

## L3-A-02｜线程 A-约束枚举｜微观经济学 → 生产运营

共享 mindset：两股边际力量此消彼长，最优解在"边际得失相抵"处取得。

### 源题（微观经济学）
垄断厂商面对需求 q = 120 − 2p，单位成本 c = 10，利润 π(p) = (p − 10)(120 − 2p)，价格 p 可取任意正实数。求利润最大化价格。

解法：一阶条件闭式解——π 是开口向下的抛物线，顶点 p* = (a + bc)/(2b) = (120 + 20)/4 = 35（或 π′(p) = 140 − 4p = 0）。
答案：35

### 目标题（生产运营）
某车间年需求 D = 5265 件，分 n 批生产（n 为正整数）。每开一批产生固定换线成本 K = 250 元；批量 Q = D/n，年均库存 Q/2，单位年持有成本 h = 4 元。年总成本
C(n) = 250·n + 4·5265/(2n) = 250n + 10530/n。
求使年总成本最小的整数批次数 n。
答案：7（整数；C(7) ≈ 3254.29 < C(6) = 3255.00）

### 照搬为什么错、需要怎么改
- 照搬（错误答案 = 6）：套用"一阶条件闭式解 + 就近取整"：n* = √(10530/250·½·…) = √42.12 ≈ 6.49，四舍五入到 6——但 C(6) = 3255 > C(7) ≈ 3254.29，真最优是 7。
- Model 哪里变了：决策变量从连续实数变为整数格点；C(n) 关于 n 在几何（对数）尺度对称而非算术对称，整数最优的分界点是几何均值 √(6×7) ≈ 6.4807 而非 6.5，本题 n* = 6.4900 恰落在 (6.4807, 6.5) 陷阱区间。
- Method 需要哪步适配：闭式驻点只用来定位候选区间，必须枚举比较 ⌊n*⌋ 与 ⌈n*⌉ 的目标函数值（更一般地对整数格点做局部枚举/DP），不能按算术距离就近取整。

### Lure（生产运营表皮、连续结构）
"化工液体按吨连续订购，订购频次 n 可取任意正实数，成本同型 C(n) = Kn + hD/(2n)，最优 n* = √(hD/2K)，代入即得 6.49 次/年"。
- 表面相似：同为批量-换线权衡、同一成本函数形状、同样的参数记号。
- 结构不同：决策域连续，驻点即最优；照搬"闭式解+就近取整"到目标题得 6（错误），真值 7。

verified：python3 对源题网格搜索确认 p* = 35；对目标题枚举 n = 1..200 得整数 argmin = 7（C(6)=3255.0000, C(7)=3254.2857），且 √42.12 = 6.48999 落于 (√42 = 6.4807, 6.5) 陷阱区间，断言通过。

## L3-E-01｜线程 E-信噪判别｜雷达工程 → 天文学

共享 mindset：可判别性 = 信号积累速度对噪声积累速度之比；信号随观测量线性累积，噪声按平方根累积，故显著性随 √(观测量) 提升。

### 源题（雷达工程）
雷达单个脉冲的目标回波幅度 s = 1.2（任意单位），接收机热噪声 RMS σ = 4.0，噪声电平固定、与回波强弱无关。对 k 个脉冲相干积累：信号变为 k·s，噪声 RMS 变为 σ√k。判定门限要求 SNR ≥ 5。求最少积累脉冲数 k。

解法：SNR(k) = k·s / (σ√k) = s√k/σ ≥ 5 ⟹ k ≥ (5σ/s)² = (20/1.2)² ≈ 277.78 ⟹ k = 278。
答案：278

### 目标题（天文学）
用 CCD 对一颗暗星测光：恒星光子率 r = 10 counts/s，天光背景率 b = 40 counts/s（背景均值可精确扣除，但其光子涨落仍在）。光子计数服从泊松统计：曝光 t 秒后总计数的噪声为 √(总计数) = √((r+b)·t)。检出要求恒星信号达到 5σ 显著。求最短整数曝光秒数 t。
答案：13（整数秒；r·t/√((r+b)t) ≥ 5 ⟹ t ≥ 25(r+b)/r² = 12.5）

### 照搬为什么错、需要怎么改
- 照搬（错误答案 = 10）：套用雷达"噪声底与信号无关"的假设，只把背景当噪声源：t ≥ 25b/r² = 25×40/100 = 10 秒——但 t = 10 时真实显著性 = 100/√500 ≈ 4.47σ < 5，未达检出门限。
- Model 哪里变了：噪声模型从"加性固定方差"（热噪声，方差与信号无关）变为"泊松计数"（方差 = 信号+背景总计数，信号自身贡献噪声）。
- Method 需要哪步适配：SNR 分母必须换成 √((r+b)t) 而非 √(b·t)（或固定 σ√k）；解出的门限从 25b/r² 变为 25(r+b)/r²，再向上取整到整数秒。

### Lure（天文表皮、固定噪声结构）
"同一台 CCD 做 0.1s 极短曝光时读出噪声主导：每帧读出噪声固定 σ_r，与光子数无关，叠加 k 帧噪声为 σ_r√k——求达到 5σ 所需帧数"，解法与雷达完全同构（固定噪声底）。
- 表面相似：同为 CCD 天文测光、同问 5σ 检出所需观测量。
- 结构不同：读出噪声主导时方差确实与信号无关；照搬该噪声模型到光子噪声主导的目标题得 10 秒（错误），真值 13 秒。

verified：python3 核验源题 k=278（SNR(278)=5.002 ≥ 5 > SNR(277)=4.993）；目标题逐整数秒扫描 t=1..99，首个真实显著性 ≥ 5 的 t = 13（σ(13)=5.099, σ(12)=4.899），天真解 t=10 处真实显著性 4.472 < 5，断言通过。

## L3-F-01｜线程 F-逆问题/源定位｜核物理·考古 → 法医学

共享 mindset：由当前观测值沿已知一阶衰减动力学反演经过的时间（逆问题：先标定速率常数，再对数反演）。

### 源题（核物理/考古）
碳-14 衰变服从 N(t) = N₀·e^(−λt)，半衰期 5730 年（即 λ = ln2/5730），衰减趋于 0。一件木器残留 C-14 为初始量的 35%。求其年代。

解法：0.35 = e^(−λt) ⟹ t = ln(1/0.35)/λ = 5730·ln(1/0.35)/ln2 ≈ 8678.5 年。
答案：≈8679 年（容差 ±10）

### 目标题（法医学）
恒温 21.0 °C 的房间内发现一具尸体。23:00 测得体表核心温 31.4 °C；次日 0:00（1 小时后）再测为 29.9 °C。牛顿冷却定律：T(t) = T_a + (T₀ − T_a)·e^(−kt)，环境温 T_a = 21.0 °C，死亡瞬间体温 T₀ = 36.8 °C，k 未知需由两次测温标定。求死亡时刻距第一次测温（23:00）多少小时（保留两位小数）。
答案：2.69 小时（容差 ±0.05；即死亡时刻约 20:19）

### 照搬为什么错、需要怎么改
- 照搬（错误答案 = 3.24 小时）：套用碳定年的纯指数模型 T(t) = T₀e^(−kt)（衰减趋于 0）：k = ln(31.4/29.9) ≈ 0.0489，t = ln(36.8/31.4)/k ≈ 3.24 小时——比真值 2.69 偏差约 33 分钟，因为它假设温度衰向 0 °C 而非环境温 21 °C，把衰减速率常数和剩余"信号"都算错了。
- Model 哪里变了：不动点从 0 变为非零环境温 T_a——指数衰减作用在偏差量 T − T_a 上而非观测量本身。
- Method 需要哪步适配：所有取对数的步骤前先做坐标平移（减去 T_a）：k = ln((31.4−21)/(29.9−21)) ≈ 0.1558/h，t = ln((36.8−21)/(31.4−21))/k = ln(15.8/10.4)/0.1558 ≈ 2.69 h。标定与反演两步都必须平移。

### Lure（法医毒理表皮、纯指数结构）
"死者血液中某药物按一级动力学消除（浓度衰向 0）：C(t) = C₀e^(−kt)。两次采血测得浓度比即 e^k，服药量已知 C₀，求服药距采血多少小时"——纯指数对数反演，无偏移项。
- 表面相似：同为法医场景、同为两次测量标定速率再回推时间。
- 结构不同：药物消除确实衰向 0，无非零不动点；照搬其解法到目标题得 3.24 小时（错误），真值 2.69 小时。

verified：python3 核验源题 t = 8678.5 年；目标题解出 k = 0.155755/h、t = 2.6850 → 2.69，并正向仿真回代：T(t)=31.4000、T(t+1h)=29.9000 与题面两次测温完全一致；天真解 3.2419 → 3.24，断言通过。

## L3-B-01｜线程 B-不变量/状态验证｜计算机科学 → 化学动力学

共享 mindset：判断状态可达性不必搜索——找一个被所有允许操作保持的守恒量（不变量），若初态与目标态的不变量取值不同则不可达。

### 源题（计算机科学）
一台机器有 7 个布尔寄存器，初始全为 0。唯一允许的原子操作：同时翻转恰好 2 个寄存器。问能否到达全 1 状态？（A. 能  B. 不能）

解法：不变量 = 值为 1 的寄存器个数的奇偶性。翻转 2 个寄存器使 1 的个数变化 −2、0 或 +2，奇偶性不变。初态 1 的个数 = 0（偶），目标 = 7（奇），奇偶不同 ⟹ 不可达。
答案：B（不能）

### 目标题（化学动力学）
密闭反应器中同一分子式的三种异构体 X、Y、Z，初始分别为 13、15、17 mol。体系中唯一发生的基元反应：两种不同异构体各 1 mol 碰撞，全部转化为第三种异构体 2 mol（X+Y→2Z、Y+Z→2X、X+Z→2Y 均可发生，次序与次数任意）。问能否通过某个反应序列使全部 45 mol 变为同一种异构体？（A. 能  B. 不能）
答案：B（不能）

### 照搬为什么错、需要怎么改
- 照搬（错误答案 = A 能）：套用源题的奇偶不变量：每步 (−1, −1, +2) 使两个物种计数的奇偶翻转、第三个不变，"奇偶和 mod 2"守恒——初态 (13,15,17) 奇偶和 = 1，目标 (45,0,0) 奇偶和 = 1，奇偶检验通过，于是天真结论是"能"。但奇偶只是必要条件，本题真正的障碍在 mod 3。
- Model 哪里变了：状态空间从 Z₂⁷（翻转、模 2 结构）变为三元非负整数计数（增量 (−1,−1,+2)，模 3 结构）；操作群不同，源题的守恒量在新操作下失去判别力。
- Method 需要哪步适配：不能照抄具体守恒量，必须按新操作重新推导不变量：每步任意两物种计数之差变化 0 或 ±3，故 两两之差 mod 3 守恒（等价地，各计数 mod 3 的多重集）。初态 mod 3 = {13,15,17} ≡ {1,0,2} 两两不同；全同态 (45,0,0) 需有两个计数 ≡ 0 (mod 3) 相等——矛盾，故不可达。
- 说明：mindset（"找操作的守恒量"）完全保持，但不变量本身必须随操作代数重造——这正是 L3"同图式、算子需替换"的定义。

### Lure（化学表皮、真奇偶结构）
"反应器中两种异构体 P、Q，初始 6 mol 与 9 mol，唯一反应：2P→2Q 或 2Q→2P（每次恰好转化 2 mol）。问能否全部变为 P？——P 的摩尔数奇偶性不变，6 为偶、15 为奇，不能"，奇偶不变量直接适用。
- 表面相似：同为异构体转化反应器、同问"能否全部变为一种"。
- 结构不同：其操作 (±2, ∓2) 天然保持各计数奇偶，奇偶即完备判据；照搬奇偶判据到三物种目标题会因"奇偶检验通过"而误判为 A 能（错误），真值 B 不能。

verified：python3 BFS 穷举——源题在 2⁷ = 128 个状态上 BFS，可达 64 个偶重量状态、全 1 不可达；目标题在 x+y+z=45 的全部组合上 BFS（可达 360 状态），(45,0,0)/(0,45,0)/(0,0,45) 均不可达；同时核验奇偶和 mod 2 在初态与目标态相等（证明天真奇偶检验确实"放行"），断言通过。
