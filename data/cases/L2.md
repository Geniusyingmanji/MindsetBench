## L2-A-01 ｜线程 A-约束枚举 ｜ 运筹物流 → 分析化学

图式：线性丢番图等式（预算/质量恰好耗尽）+ 奇偶耦合约束 + 线性上界，共同切割整点可行域，逐层枚举计数。

### 源题（运筹/物流）

一艘驳船本航次载重必须恰好 29 吨。可装四类货物：发电机组每台 9 吨、沙袋每袋 1 吨、电缆盘每盘 5 吨、木箱每箱 4 吨，数量均为非负整数，且至少装 1 台发电机组。装载规程两条：
1. 沙袋与电缆盘共用成对的双联货架，二者数量必须同奇偶；
2. 系固规则：沙袋数 ≤ 2×发电机组数 + 电缆盘数 + 2。

问满足全部规程的装载方案 (a,b,c,d)=(机组,沙袋,缆盘,木箱) 共有多少种？

解法（算子序列）：
1. 列质量等式 9a + b + 5c + 4d = 29，a≥1；
2. 外层枚举 a ∈ {1,2,3}（9a≤29）；
3. 中层枚举 c、内层枚举 d，b 由等式唯一确定；
4. 对每个候选逐条核验隐式约束：b≥0、b≡c (mod 2)、b ≤ 2a+c+2；
5. 计数。可行解共 9 个：(1,4,0,4),(1,0,0,5),(1,3,1,3),(1,6,2,1),(1,2,2,2),(1,5,3,0),(1,1,3,1),(1,0,4,0),(3,2,0,0)。

答案：9

### 目标题（分析化学/质谱）

质谱测得某未知有机物的标称分子量（整数质量：C=12, H=1, N=14, O=16）为 101。设分子式为 CxHyNzOw，x≥1，y,z,w≥0 均为整数。仅保留化合价可行的分子式：不饱和度 DBE = (2x + 2 + z − y)/2 必须是非负整数。

问候选分子式共有多少个？（答案为一个整数）

答案：10 ｜ answer_type: numeric ｜ tolerance: 0
（穷举核验：C2H3N5, C3H3N3O, C4H3NO2, C4H7N3, C5H7NO, C6H11N, C7H3N 等共 10 个；氮规则"奇质量⇒奇数个 N"作为奇偶约束的推论自动涌现。）

### mapping

| 源（物流） | 目标（化学） |
| --- | --- |
| 总载重 29 吨 | 标称分子量 101 |
| 机组/沙袋/缆盘/木箱件数 (a,b,c,d) | 元素个数 (x,y,z,w)=(C,H,N,O) |
| 单件重量 9/1/5/4 | 原子整数质量 12/1/14/16 |
| "至少 1 台机组" | x≥1（有机物必含碳） |
| 双联货架同奇偶规程 | DBE 为整数 ⇒ y≡z (mod 2)（氮规则） |
| 系固上界 b≤2a+c+2 | DBE≥0 ⇒ y≤2x+2+z（氢上限） |

- shared_relations：线性等式恰好耗尽预算；奇偶耦合约束；线性不等式上界；解=可行域整点集合；嵌套枚举+逐条约束核验的计数算子。
- varied：Surface（词汇、数值、约束的叙事包装全换）与 Domain（物流→化学）翻转；Model（丢番图+奇偶+上界的整点计数）、Method（外层枚举→内层确定→约束过滤→计数）、Schema（显式+隐式约束切割可行域）完全保持。目标题的奇偶与上界约束不再显式给出，而是折叠进"DBE 为非负整数"一条化学判据中，需解题者自行展开。

### lure（化学皮、异构枚举核）

题：C4H10O 有多少种结构异构体？【解答】按碳骨架分类枚举：丁醇类 4 种（正丁醇、异丁醇、仲丁醇、叔丁醇），醚类 3 种（甲丙醚、甲基异丙基醚、乙醚），共 7 种。
- 表面像在哪：同为"给定分子组成→数出有多少种"的化学计数题，词汇（分子式、异构、计数）与目标题高度重叠。
- 结构差在哪：异构体计数是固定原子多重集上的图枚举（数不同的连接方式），无丢番图等式、无整点可行域；目标题是变元素组成的格点计数。照搬骨架分类法对目标题无从下手，照搬格点法数异构体必错。

## L2-B-02 ｜线程 B-不变量/状态验证 ｜ 粒子物理 → 分布式计算

图式：三类状态两两相互作用生成第三类（计数变化 (−1,−1,+2)），总数守恒，两两计数差 mod 3 是转移不变量，用它判定"全同终态"可达性。

### 源题（粒子物理）

某等离子体阱中有三种准粒子 X、Y、Z，初始计数 X=14, Y=11, Z=6（共 31，实验期间总数守恒）。唯一允许的相互作用：两个不同种的准粒子对撞后湮灭，同时产生第三种准粒子 2 个。问：经过若干次对撞后，阱中是否可能只剩单一种准粒子？若可能，是哪一种？

解法（算子序列）：
1. 写出转移对计数向量的作用：任一对撞使两种计数 −1、第三种 +2；
2. 找不变量：任意两种计数之差 mod 3 在所有转移下不变（−1−(−1)=0；−1−2≡0；2−(−1)≡0 (mod 3)）；
3. 目标态检验：全 X 态 (31,0,0) 要求 Y−Z≡0 (mod 3)，初始 11−6=5≢0，排除；全 Y 态要求 X−Z≡0，14−6=8≢0，排除；全 Z 态要求 X−Y≡0，14−11=3≡0，必要条件满足；
4. 可达性构造（必要⇒充分的验证）：先让 X、Y 各自对撞消耗（每次 X−1,Y−1,Z+2），11 次后到 (3,0,28)；再用 X 与 Z 对撞造出 Y、Y 与 X 对撞……交替把余下 3 个 X 消干净（BFS 已证 (0,0,31) 可达）。

答案：Z

### 目标题（分布式计算）

一个 44 节点集群做三值寄存器的反熵修复，节点状态 ∈ {s1, s2, s3}，当前 s1:20, s2:15, s3:9。修复协议：每轮任选两个状态不同的节点做一次同步，冲突消解规则是双方都改写为第三个状态（例如 s1 与 s2 同步后双方都变 s3）。节点数不变。

问：集群能否收敛到所有节点同一状态？若能，收敛态只可能是哪一个？（答案填 s1 / s2 / s3 / none）

答案：s1 ｜ answer_type: string
（不变量检验：全 s1 需 s2−s3=15−9=6≡0 (mod 3) ✓；全 s2 需 20−9=11≢0 ✗；全 s3 需 20−15=5≢0 ✗。BFS 全状态空间确认 (44,0,0) 可达且唯一。）

### mapping

| 源（粒子物理） | 目标（分布式计算） |
| --- | --- |
| 准粒子种类 X/Y/Z | 节点状态 s1/s2/s3 |
| 种群计数 (14,11,6) | 状态计数 (20,15,9) |
| 对撞湮灭并产生第三种×2 | 同步冲突消解：双方改写为第三态 |
| 粒子总数守恒 31 | 节点总数守恒 44 |
| "只剩单一种" | "收敛到全同状态" |

- shared_relations：转移算子 = 两分量 −1、第三分量 +2；总和不变量；两两差 mod 3 不变量；终态可达 ⇔ 对应差 ≡0 (mod 3)（计数为正时充分）。
- varied：Surface、Domain（物理实验叙事→共识协议叙事，计数全换）翻转；Model（(−1,−1,+2) 转移系统的可达性）、Method（找 mod-3 不变量→逐终态检验→构造可达）、Schema（不变量守恒排除终态）保持。
- provenance 注：形式内核为经典"变色龙型"不变量问题的深度改编——两侧叙事、参数、提问均重制，且要求给出唯一可达态而非仅判可行。

### lure（分布式皮、传染动力学核）

题：同一集群跑 last-writer-wins 反熵：两个状态不同的节点同步时，时间戳新的一方获胜，另一方被改写（每轮改写一个节点）。初始 s1:20, s2:15, s3:9，s3 的时间戳最新。问最终收敛到哪个状态？【解答】LWW 下每次同步严格增加最新时间戳状态的计数，单调收敛到 s3；答案 s3。
- 表面像在哪：同样是"三状态副本 + 两两同步 + 问收敛到哪个状态"，词汇（反熵、冲突消解、收敛）几乎逐词重合。
- 结构差在哪：LWW 转移是 (−1,+1)，不产生第三态，无 mod-3 差量不变量，收敛态由时间戳序全序决定而与计数无关。把"最新/最多者胜"直觉或 (−1,+1) 分析照搬到 (−1,−1,+2) 系统会得出错误收敛态。

provenance: adapted-from-classic-invariant-puzzle（变色龙型，重参数化+双侧换域+改问法） ｜ verified: python3 对两侧初始计数做全状态空间 BFS，逐一确认可达/不可达终态集合 = mod-3 判据预测。

## L2-C-03 ｜线程 C-分解规划 ｜ 电气工程 → 水利工程

图式：线性流网络（势差 = 阻抗 × 流量）的嵌套串并联结构，自内向外分块折叠求总流，再自外向内回代分流。

### 源题（电气工程）

32 V 电源经一个 2 Ω 限流电阻接到节点 N，N 到地有两条支路：支路 α 为单个 12 Ω 电阻；支路 β 为一个 8 Ω 电阻串联"两只 8 Ω 电阻的并联对"。求并联对中任一只 8 Ω 电阻上的电流。

解法（算子序列）：
1. 识别层级：并联对(8∥8) 嵌在支路 β 内，β 与 α 并联，再与 2 Ω 串联；
2. 折叠最内层：8∥8 = 4 Ω；
3. 折叠支路 β：8+4 = 12 Ω；折叠并联层：12∥12 = 6 Ω；折叠串联：2+6 = 8 Ω；
4. 总电流 I = 32/8 = 4 A；
5. 回代：N 点电位 32 − 4×2 = 24 V ⇒ β 支路电流 24/12 = 2 A；
6. 再回代：并联对两端电压 24 − 2×8 = 8 V ⇒ 每只 8 Ω 电流 8/8 = 1.0 A。

答案：1.0 A

### 目标题（水利工程/市政管网）

某低速供水管网工作在层流区，每段管道满足线性压降律 ΔP = R·Q（R 单位 kPa·s/L，Q 单位 L/s）。泵站与末端水库间维持 360 kPa 压差。水先经一段 R=2 的主管到分水井 J；J 到水库有两条路线：路线一为单管 R=20；路线二为一段 R=12 的管道，随后分成两根 R=16 的并行支管，在水库前汇合。

求任一根 R=16 支管中的流量（L/s）。

答案：7.5 ｜ answer_type: numeric ｜ tolerance: 0.05
（折叠：16∥16=8 → 12+8=20 → 20∥20=10 → 2+10=12；Q总=360/12=30；J 井压头 300 kPa ⇒ 路线二 15 L/s；并行段压差 120 kPa ⇒ 每根 16 支管 7.5 L/s。）

### mapping

| 源（电路） | 目标（管网） |
| --- | --- |
| 电压差 32 V | 泵站压差 360 kPa |
| 电流 I | 体积流量 Q |
| 电阻 R (Ω) | 水力阻力 R (kPa·s/L) |
| 欧姆定律 V=IR | 层流压降律 ΔP=RQ |
| 节点电流守恒（KCL） | 分水井质量守恒 |
| 串联电阻相加 / 并联调和平均 | 串联管阻相加 / 并联管阻调和平均 |
| 求并联对中单只电阻的电流 | 求并行支管中单根管的流量 |

- shared_relations：线性本构关系；两类守恒（回路势差、节点流量）；串联加和与并联调和的折叠规则；"折叠求总量→回代求分量"的双向算子序列（6 步逐一对应）。
- varied：Surface、Domain（电学→水力学，全部数值重设）翻转；Model（嵌套串并联线性网络）、Method（自内向外折叠+自外向内回代）、Schema（分解规划：把整体网络切成可归约块）保持。

### lure（水利皮、非线性湍流核）

题：某高速输水系统处于湍流区，压降服从平方律 ΔP = k·Q²。两根 k1=4、k2=9（kPa·s²/L²）的管道并联，两端压差 144 kPa，求总流量。【解答】平方律下并联合成规则为 1/√k_eq = 1/√k1 + 1/√k2 = 1/2+1/3 = 5/6 ⇒ k_eq = 36/25；Q = √(144/1.44) = 10 L/s（即各管 Q=√(ΔP/k)：6+4=10）。
- 表面像在哪：同为"并联水管、给压差求流量"，词汇（管道、并联、压差、流量）与目标题完全一致。
- 结构差在哪：湍流平方律是非线性本构，并联合成走 1/√k 相加而非调和平均，串并联折叠代数整个不同。把 lure 的合成公式或"先开方"套路搬到线性层流网络（或反向照搬调和平均到湍流）都会算错。

provenance: original ｜ verified: python3 逐步折叠复算 + 用节点方程线性求解交叉验证（两法一致）。

## L2-E-04 ｜线程 E-信噪判别 ｜ 医学诊断 → 网络安全

图式：极低先验下，检出信号（真阳性率）必须与假阳性噪声底（(1−先验)×FPR²）比较；两次条件独立检出的贝叶斯串联更新，基率谬误陷阱。

### 源题（医学诊断）

某罕见代谢病患病率 1%。筛查试验敏感度 85%、特异度 95%。对同一受检者做两次条件独立（给定患病状态下独立）的该试验，两次均为阳性。求此人实际患病的概率（百分数，保留 1 位小数）。

解法（算子序列）：
1. 识别先验 p=0.01，单次似然比结构：阳性|患病 0.85，阳性|健康 0.05；
2. 条件独立 ⇒ 双阳性似然：患病 0.85²=0.7225，健康 0.05²=0.0025；
3. 贝叶斯：分子 0.01×0.7225=0.007225；噪声项 0.99×0.0025=0.002475；
4. 后验 = 0.007225/(0.007225+0.002475) = 0.7448 → 74.5%。
（对照直觉：单次阳性后验仅 14.6%，第二次阳性把信号抬出噪声底。）

答案：74.5%

### 目标题（网络安全）

某企业网关流量中恶意会话的基率为 0.2%。部署两个条件独立（给定会话真实类别时告警相互独立）的入侵检测器，二者对恶意会话的检出率（TPR）均为 90%，对正常会话的误报率（FPR）均为 4%。某会话被两个检测器同时告警。

求该会话确为恶意的概率（百分数，保留 1 位小数）。

答案：50.4 ｜ answer_type: numeric ｜ tolerance: 0.1
（0.002×0.9² = 0.00162；0.998×0.04² = 0.0015968；后验 = 0.00162/0.0032168 = 50.36% → 50.4。双告警下仍只有约一半是真恶意——噪声底与信号同量级。）

### mapping

| 源（医学） | 目标（安全） |
| --- | --- |
| 患病率 1% | 恶意会话基率 0.2% |
| 患病/健康 | 恶意/正常会话 |
| 试验敏感度 85% | 检测器 TPR 90% |
| 1−特异度 = 5% | FPR 4% |
| 两次独立复检均阳性 | 两个独立检测器同时告警 |
| 患病后验 | 恶意后验 |

- shared_relations：后验 = p·s² / (p·s² + (1−p)·f²)；条件独立 ⇒ 似然平方；信号项与假阳性噪声底同量级时先验主导；"先验→双重似然→归一化"的三步算子。
- varied：Surface、Domain（临床叙事→安全运营叙事，全部率值重设，"同一试验做两次"改写为"两个异构检测器"）翻转；Model（二元假设+双条件独立观测的贝叶斯更新）、Method、Schema（信噪判别：检出必须压过噪声底）保持。

### lure（安全皮、平衡先验核）

题：在红蓝对抗评测中，测试集由 5000 条恶意与 5000 条正常会话构成。某检测器整体准确率 96%（对两类错误率对称）。评测集中一条会话被告警，问它是恶意的概率？【解答】先验 50% 且错误对称时，后验 = 0.96×0.5/(0.96×0.5+0.04×0.5) = 96%——"准确率即告警可信度"在平衡集上成立。
- 表面像在哪：同为"检测器告警后求恶意概率"，词汇（检测器、准确率、告警、恶意会话）与目标题重合，且其解答给出一个看似通用的捷径。
- 结构差在哪：lure 的先验是人为平衡的 50%，基率项在贝叶斯公式中约掉，"准确率≈后验"是该特例的巧合；目标题基率 0.2%，噪声底由海量正常流量贡献，照搬捷径会把 50.4% 报成 ~96%（把 TPR 当后验），负迁移幅度极大。

provenance: original ｜ verified: python3 按贝叶斯公式精确计算两侧后验（源 74.4845%、目标 50.3606%），与手推一致。

## L2-F-05 ｜线程 F-逆问题/源定位 ｜ 金融 → 药理学

图式：一阶指数过程 A·e^{±kt}，由两次观测的比值反演速率常数，再结合已知初值把"源事件时刻"回溯出来（观测→参数→事件定位的三段逆推）。

### 源题（金融）

某账户开户时一次性存入 5,000 元，此后按未知的连续复利年利率 r 增长，无其他存取。2019-01-01 查得余额 7,200 元；2023-01-01 查得余额 10,368 元。问开户日在 2019-01-01 之前多少年？（保留 1 位小数）

解法（算子序列）：
1. 模型 B(t) = 5000·e^{rt}（t 自开户起）；
2. 比值消元定参：10368/7200 = 1.44 = e^{4r} ⇒ r = ln 1.44 / 4 ≈ 0.09116；
3. 回溯源事件：7200/5000 = 1.44 = e^{r·t₁} ⇒ t₁ = ln 1.44 / r = 4.0 年。

答案：4.0 年

### 目标题（药理学）

患者经静脉推注一剂 600 mg 药物，表观分布容积 40 L（推注瞬间血药浓度 = 剂量/Vd）。该药按一级动力学消除。护士忘记记录给药时间，只有两次采血：第一次血药浓度 4.8 mg/L，5 小时后第二次 1.5 mg/L。

问第一次采血发生在给药后多少小时？（保留 2 位小数）

答案：4.90 ｜ answer_type: numeric ｜ tolerance: 0.02
（C0 = 600/40 = 15 mg/L；k = ln(4.8/1.5)/5 = ln 3.2/5 ≈ 0.23263 h⁻¹；t₁ = ln(15/4.8)/k = ln 3.125/0.23263 ≈ 4.898 → 4.90 h。）

### lure（药理皮、零级动力学核）

题：一名饮酒者血中乙醇按零级动力学（恒速）消除，速率 0.15 g/L/h。22:00 测得血醇 1.2 g/L，24:00 测得 0.9 g/L，已知饮酒结束瞬间血醇为 1.8 g/L，问饮酒结束于几点？【解答】零级=线性下降：验证速率 (1.2−0.9)/2h=0.15 ✓；回溯 (1.8−1.2)/0.15 = 4 h ⇒ 18:00。
- 表面像在哪：同为"两次采血 + 已知初始浓度 + 回溯给药/饮酒时刻"的药代动力学题，词汇与数据形态（两个时刻两个浓度）与目标题几乎一致。
- 结构差在哪：零级消除是线性差分结构（差值/速率），一级消除是指数比值结构（对数/比值）。把 lure 的"浓度差÷恒定速率"搬到一级动力学会得 (15−4.8)/0.66=15.5 h 之类的错误回溯；反之把对数比值法用于零级也错。

## L2-G-06 ｜线程 G-混合亚群建模 ｜ 微生物学 → 经济/营销

图式：总体观测 = 两个衰减速率已知、规模未知的亚群指数响应之和；用两个时刻的聚合观测解 2×2 线性方程组，反演隐藏的亚群构成。

### 源题（微生物学）

一批临床分离菌是敏感株与耐药株的混合物，两株初始数量均未知。在恒定抗生素暴露下，敏感株按 e^{−0.9t} 衰减、耐药株按 e^{−0.1t} 衰减（t 单位小时，速率已知）。平板计数：t=1 h 总活菌 2.938×10⁶ CFU，t=3 h 总活菌 1.077×10⁶ CFU。

求初始菌群中耐药株的占比（百分数，保留 1 位小数）。

解法（算子序列）：
1. 设隐藏亚群初始量：敏感 a、耐药 b；
2. 列聚合观测方程组：a·e^{−0.9} + b·e^{−0.1} = 2.938×10⁶；a·e^{−2.7} + b·e^{−0.3} = 1.077×10⁶；
3. 解 2×2 线性系统（系数为已知指数值）：a ≈ 5.00×10⁶，b ≈ 1.00×10⁶；
4. 换算构成：b/(a+b) ≈ 16.7%。

答案：16.7%

### 目标题（经济/营销）

某订阅产品一个新用户 cohort 由"浅度用户"与"核心用户"两段构成，两段初始人数均未知。行业校准给出留存曲线：浅度段活跃人数按 e^{−0.35m} 衰减、核心段按 e^{−0.05m} 衰减（m 为月龄，速率已知）。该 cohort 实测：第 2 个月活跃 5,782 人，第 6 个月活跃 2,461 人。

求该 cohort 初始构成中核心用户的占比（百分数，保留 1 位小数）。

答案：20.0 ｜ answer_type: numeric ｜ tolerance: 0.5
（解 a·e^{−0.7}+b·e^{−0.1}=5782，a·e^{−2.1}+b·e^{−0.3}=2461 ⇒ a≈8000（浅度）、b≈2000（核心）⇒ 20.0%。）

### mapping

| 源（微生物） | 目标（营销） |
| --- | --- |
| 敏感株 / 耐药株 | 浅度用户段 / 核心用户段 |
| 抗生素暴露时长 t (h) | cohort 月龄 m |
| 衰减常数 0.9 / 0.1 | 流失常数 0.35 / 0.05 |
| 两次平板总计数 | 两个月份的总活跃数 |
| 未知初始菌量 (a,b) | 未知初始段人数 (a,b) |
| 耐药株初始占比 | 核心用户初始占比 |

- shared_relations：聚合观测 = 亚群指数响应的加权和；速率已知、权重未知；两时刻观测 ⇒ 2×2 线性系统恰定；快衰减亚群主导早期、慢衰减亚群主导晚期；"设亚群→列聚合方程→解线性系统→换算占比"的算子序列。
- varied：Surface、Domain（培养皿叙事→增长运营叙事，速率与数值全换）翻转；Model（双组分指数混合的权重反演）、Method、Schema（混合亚群建模：拒绝同质总体假设）保持。

### lure（营销皮、同质单指数核）

题：某 cohort 用户同质流失，活跃人数 N(m)=N0·e^{−km}。第 2 个月活跃 6,400 人，第 5 个月活跃 3,200 人。问第 8 个月预计活跃多少人？【解答】比值 6400/3200=2=e^{3k} ⇒ 每 3 个月减半；第 8 个月 = 3200/2 = 1,600 人。
- 表面像在哪：同为"cohort 留存 + 两个月份活跃数"的订阅业务题，词汇（cohort、留存、活跃、月龄）与目标题一致，且解法（取比值拟合单指数）非常顺手。
- 结构差在哪：lure 是同质单指数（1 参数，比值即可定），目标是双亚群混合（2 个隐藏权重，比值不再对应任何单一速率）。照搬"取比值求 k"于目标题会得到介于 0.05 与 0.35 之间的伪速率，且完全无法回答"占比"——混合结构被压平即答错。

provenance: original ｜ verified: python3 生成端正向模拟（a=5×10⁶/1×10⁶、8000/2000）得观测值，再从题面给出的舍入观测用 numpy 解线性系统反演，源 16.67%、目标 20.0%，均落在容差内。
