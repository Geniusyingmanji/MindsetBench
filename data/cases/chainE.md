# 线程 E 完整迁移链 E-chain-01：信噪判别

> 定位：SPEC §7 缺口 3 的补齐——同一 Schema 贯穿 L1→L4 的完整链，四个目标题共享同一个源题，用于画单线程迁移梯度曲线（增益(L1)…增益(L4) 的衰减率）。
> ID 规则：L{k}-E-C1；每行 JSONL 额外字段 `"chain": "E-chain-01"`，source 字段为同一共享源题。
> 所有数值答案（含照搬错误答案）已用 python3 逐一验证（边界整数两侧断言 + 全区间扫描），见文末验证记录。

## 固定抽象图式

多源真信号与噪声叠加到达观测端；可判别 ⟺ 信号超过噪声底一个与置信要求挂钩的裕量 z；信号随观测量线性累积、噪声按平方根累积，故显著性 ∝ √观测量，所需观测量由「裕量×单位噪声 / 单位信号」的平方反解。

三个不变的图式步骤（源题解答显式暴露，四级目标题逐级剥离外衣后仍须复现）：
① 噪声底估计（无信号条件下标定噪声、确定其随观测量的累积规律）→ ② 裕量设定（把置信/虚警要求翻译成噪声底之上的倍数 z）→ ③ 累积量反解（信号累积 ≥ z×噪声累积，解出最小观测量并取整）。

## 共享源题（通信工程—深空导频捕获）

### 题面
深空探测器向地面站发送捕获导频。接收机每个码片输出 y_i = s + n_i：导频存在时信号幅度恒为 s = 0.5（归一化单位）；n_i 为相互独立的零均值高斯噪声。地面站在探测器静默的空闲时段测得单码片噪声标准差 σ = 6.0（噪声底标定）。接收机把 k 个码片相干累加为检测统计量 T_k = Σy_i：信号部分线性累积为 k·s，噪声标准差按平方根累积为 σ√k。任务规范要求虚警概率 ≤ 10⁻⁶，等价于 T_k 须超过累加后噪声标准差的 z = 4.8 倍（Q(4.8)≈7.9×10⁻⁷，z 值题中给定）。求可靠捕获导频所需的最少相干累加码片数 k。

### 逐步解答（显式暴露图式）
1. 噪声底估计：空闲时段标定单码片噪声 σ = 6.0；k 个独立噪声样本求和后方差相加，故累加后噪声底 = σ√k（√累积）。
2. 裕量设定：置信要求（虚警 ≤ 10⁻⁶）翻译成噪声底之上的判别裕量：需 T_k ≥ z·σ√k，z = 4.8。
3. 累积次数反解：信号线性累积为 k·s，判别条件 k·s ≥ z·σ√k ⟺ s√k/σ ≥ z ⟺ k ≥ (zσ/s)² = (4.8×6.0/0.5)² = 57.6² = 3317.76。最小整数 k = 3318（边界复核：SNR(3318) = 4.8002 ≥ 4.8，SNR(3317) = 4.7995 < 4.8）。

答案：3318

## L1-E-C1｜同域换皮（Surface 翻转；Domain/Model/Method/Schema 全同）

### 目标题（通信工程—水声通信）
水下声学调制解调器要在开阔海域捕获对端发来的同步前导。接收机每个符号观测 y_i = a + w_i：前导存在时符号幅度恒为 a = 0.32；w_i 为相互独立的零均值高斯噪声，安静接收窗（对端静默时段）测得单符号噪声标准差 σ = 4.0。调制解调器把 k 个符号相干累加：信号累积为 k·a，噪声标准差为 σ√k。链路规范要求虚警概率 ≤ 1.1×10⁻⁴，对应累加统计量须达噪声标准差的 z = 3.7 倍（z 题中给定）。求可靠捕获同步前导的最少累加符号数 k。

答案：2140（k ≥ (3.7×4.0/0.32)² = 46.25² = 2139.0625；边界：z_eff(2140)=3.70008 ≥ 3.7，z_eff(2139)=3.69995 < 3.7）

同构性：深空↔水声只是表皮；对象双射（码片↔符号、s↔a、空闲时段↔安静接收窗、10⁻⁶↔1.1×10⁻⁴），公式逐符号对应。lure：无（SPEC 约定 L2 起配）。

## L2-E-C1｜跨科同构（Surface+Domain 翻转；Model/Method/Schema 全同）

### 目标题（医学检验—临床化学）
临床实验室要判定尿样中是否含痕量药物代谢物 M。分光光度计单次读数 = 真实吸光贡献 + 仪器噪声：若 M 存在，其吸光贡献恒为 c = 0.004 AU；仪器噪声为独立零均值随机误差，实验室用空白样本反复测量标定出单次读数噪声标准差 σ = 0.05 AU。检验流程对同一份样本重复读数 k 次取平均：平均值中 M 的贡献仍为 c，噪声标准差降为 σ/√k。质控规范要求假阳性率 ≤ 0.1%，对应平均读数须超过空白基线 z = 3.1 倍平均噪声标准差（z 题中给定）。求满足质控要求的最少重复读数次数 k。

答案：1502（c ≥ zσ/√k ⟺ k ≥ (zσ/c)² = (3.1×0.05/0.004)² = 38.75² = 1501.5625；边界：z_eff(1502)=3.10045 ≥ 3.1，z_eff(1501)=3.09942 < 3.1）

同构性：求和统计量与取平均统计量相差常数因子 k，两边同除 k 后是同一不等式——Model/Method 逐步对应（噪声底标定：空闲时段↔空白样本；虚警↔假阳性；裕量 z 同位）。剥掉医学检验外衣后与源题是同一道题。

### Lure（同学科异结构：贝叶斯基率翻转）
某毒品初筛试验假阳性率 0.1%、灵敏度 99%，受检人群真实使用率 0.5%。某人初筛呈阳性，求其真实使用毒品的概率。
- 表面相似：同为医学检验，同样围绕"假阳性率 0.1%"与痕量判别下结论。
- 结构不同：低先验下的贝叶斯后验翻转——无重复观测、无 √k 累积、无裕量设定；照搬其解法会把目标题引向先验/后验计算，而目标题问的是"如何设计重复次数压低噪声底"，两者不共享 Model。

## L3-E-C1｜跨域近同构（Surface+Domain 翻转，Model 近似、Method 需适配；Schema 同）

### 目标题（辐射监测—核安全）
口岸辐射门检的手持伽马谱仪排查一件疑似含弱放射源的行李。放射源净计数率 r = 7 counts/s；现场天然本底计数率 b = 45 counts/s（本底均值已长期标定、可从总计数中精确扣除，但涨落仍在）。伽马计数服从泊松统计：计数 t 秒后总计数的标准差为 √((r+b)t)——源自身的计数同样贡献涨落。判定规程要求扣除本底后的净信号达到总涨落的 z = 4 倍（对应误报率约 3.2×10⁻⁵，z 题中给定）。求出具"含放射源"判定所需的最短整数计数秒数 t。

答案：17（rt ≥ z√((r+b)t) ⟺ t ≥ z²(r+b)/r² = 16×52/49 = 16.98；边界：显著性(17)=4.0024 ≥ 4，显著性(16)=3.8829 < 4）

### 照搬为什么错、需要怎么改
- 照搬（错误答案 = 15）：套用源题"噪声底与信号无关、只由环境标定"的模型，噪声只算本底涨落 √(bt)：t ≥ z²b/r² = 16×45/49 = 14.69 → 15。t = 15 时真实显著性 = 105/√(52×15) = 3.760 < 4，未达判定门限。
- Model 哪里变了：噪声模型从加性固定方差（高斯热噪声，与信号无关）变为泊松散粒噪声（方差 = 信号+本底总计数，信号自带涨落）。
- Method 需要哪步适配：显著性分母由 σ√k 型（仅环境噪声底）换成 √((r+b)t)，反解公式从 (zσ/s)² 改写为 z²(r+b)/r²，再向上取整。

### Lure（照搬天真版，换上目标域表皮）
同一台伽马谱仪制冷失效后由读出电子学噪声主导：每次读出叠加固定 RMS 为 σ_e 的电子学噪声、与计数多少无关；k 次读出累加后信号为 k·s、噪声为 σ_e√k，求达到 4 倍显著所需读出次数。
- 表面相似：同一台谱仪、同一安检场景、同问"多少次观测达 4 倍显著"。
- 结构不同：电子学噪声确实与信号无关（lure 内部自洽、解法与源题全同构）；把该噪声模型照搬到泊松计数主导的目标题会漏掉信号自身涨落项 rt，得 15（错误），真值 17。

## L4-E-C1｜跨域远类比（Surface/Domain/Model/Method 全异；仅 Schema 共享）

### 目标题（生态监测—种群趋势判别）
某保护区对雪豹做年度种群指数调查（对数尺度）。指数逐年演化受两类扰动：
① 环境过程扰动：每年一次独立冲击 ε_i（零均值、标准差 σ_e = 0.11），冲击永久并入种群轨迹（坏年景压低的基数带进以后所有年份）；
② 调查观测误差：每年估计值带独立测量误差（零均值、标准差 σ_m = 0.12），只影响当年读数、不进入种群轨迹。
管理方担心存在真实持续衰退：真实趋势为每年下降 δ = 0.06（对数单位）。以第 0 年读数为基线，监测到第 t 年时比较两次读数之差。宣布"确认衰退"要求累计下降量超过"无趋势纯随机波动"假设下该差值标准差的 z = 2.33 倍（对应误判率 ≤ 1%，z 题中给定）。

(a) 无趋势假设下，第 t 年读数与第 0 年读数之差的方差随 t 如何构成？（单选）
A. 两类扰动的方差都随 t 线性累积　B. 过程扰动方差随 t 线性累积（标准差 ∝ √t），观测误差不随 t 累积（仅两端点各计一次）　C. 两类扰动都不累积，噪声底恒定　D. 过程扰动不累积，观测误差方差随 t 线性累积
(b) 按 (a) 的正确模型，最早第几年可宣布"确认衰退"？（最小整数 t）
答案格式：「选项字母,整数」。

答案：B,21（判别条件 δt ≥ z√(σ_e²t + 2σ_m²)，即 0.06t ≥ 2.33√(0.0121t + 0.0288)；边界：t=21 时 1.26 ≥ 1.2393，t=20 时 1.20 < 1.2125）

### 仅剩图式 Schema：模型与算子全异
- Model 异：从"iid 观测求和的检测统计量"变为"带漂移随机游走的端点差判别 + 非累积观测误差"——需先识别什么是噪声底（过程扰动的随机游走累积项 σ_e²t 是主导噪声底，观测误差只在两端点各进一次方差）、什么是裕量（误判率 1% ⟹ z=2.33）。
- Method 异：无封闭平方公式可套——判别不等式含常数项 2σ_m²，需平方后解一元二次或整数扫描；照搬源算子链（比值→平方→取整）无从下手。
- 照搬源公式的错误答案：把 σ_e 当唯一"单位观测噪声"套 t ≥ (zσ_e/δ)² = 18.25 → 19（错误），漏掉端点观测误差项；若更进一步把噪声底当恒定（不随年累积、σ_tot=√(σ_e²+2σ_m²)）则得 8（错误）。真值 21。
- 共享的仅是 Schema：累计下降量（信号）随年数线性累积；主导噪声按 √t 累积；可判别 = 信号 ≥ 噪声底 × 置信裕量。

### Lure（同域异图式：标记重捕比例估计）
为核实该保护区雪豹绝对数量，红外相机个体识别库已"标记" 24 只；次年独立调查识别出 30 只个体，其中 9 只是库中已知个体。用 Lincoln–Petersen 法估计种群规模（24×30/9 = 80）。
- 表面相似：同一保护区、同为雪豹种群监测与调查设计，同样服务于"种群是否出问题"的管理决策。
- 结构不同：图式是"两次抽样重叠比例反推总体规模"（比例估计/超几何），没有信号累积、噪声底、裕量中的任何一环；照搬其思路无法产生趋势判别所需的 √t 噪声模型与置信裕量设定。

## 难度持平性说明（结构距离单调递增、计算量持平）

结构距离严格单调（按 SPEC §1 四元组翻转计数）：
| 级 | Surface | Domain | Model | Method | Schema | 翻转成分 |
| --- | --- | --- | --- | --- | --- | --- |
| L1 | 异 | 同 | 同 | 同 | 同 | 1 |
| L2 | 异 | 异 | 同（同构） | 同（逐步对应） | 同 | 2 |
| L3 | 异 | 异 | 近似（噪声模型变） | 需适配（分母/反解式换） | 同 | 3（其中 Model/Method 为部分翻转） |
| L4 | 异 | 异 | 异（随机游走端点差） | 异（建模选择+二次不等式） | 仅 Schema | 4（Model/Method 完全翻转） |

计算量持平（刻意不用算术复杂度冒充结构距离，四题均为 2–4 位数的一次乘除+平方+取整量级）：
- L1/L2：同一封闭式 k = ⌈(zσ/s)²⌉，两次乘除一次平方；L2 仅多一步"取平均 ⟺ 求和"的常数因子等价改写。
- L3：适配后仍是一次封闭式 t = ⌈z²(r+b)/r²⌉，算术量与 L1/L2 持平；新增成本全部在"识别噪声模型变化"这一结构步，而非计算步。
- L4：数值部分是单变量不等式 0.06t ≥ 2.33√(0.0121t+0.0288)（平方后一元二次，或 ~20 个整数点扫描），算术量与前三级同量级；新增的 (a) 小问成本是认知性的（判断哪类噪声累积），不是计算性的。

冷启动难度自评（20–60% 目标区间；同 SPEC §7 缺口 2，待 target-only 实测校准）：
L1 ≈ 55%（2139.0625→2140 的边界取整 + ≥ 号方向）；L2 ≈ 50%（平均统计量下 √k 方向易写反）；L3 ≈ 40%（漏信号自涨落项即落入 15 的陷阱）；L4 ≈ 25%（两类噪声分解、端点误差计两次、非封闭式反解三重门槛 + 双段答案防蒙对）。

单调性预期（SPEC §2 约束 5）：with-source 增益应 L1 ≥ L2 ≥ L3 ≥ L4；lure 条件下 L3 预计负迁移最深（lure 即天真照搬版）。
