# 多跳长链 B-multihop-01（线程 B-不变量验证）

> 与 chainA/chainE 的区别：那两条链是"源固定、只有目标动"（同一源题配 L1–L4 四个目标）；本链是**连环迁移**——同一抽象图式在 P0→P1→P2→P3→P4→P5 六个节点间接力，**每跳的源题是上一跳的题**，学科每跳都换。测的是迁移的传递性：在 Pi→Pi+1 学到的映射能否接力到下一跳。
>
> 固定图式 Schema："操作保持的不变量决定可达性/终态——某个守恒量在所有允许操作下不变，可达性/终态由初态所在的不变量类别一票判定。"解法三步式：**找不变量 → 验类别 → 判可达（不可达一票否决 + 类内构造）**。
>
> 结构距离逐跳升级：跳1 仅翻 Surface（近同构）；跳2 翻 Domain 仍严格同构；跳3 操作集变、不变量需重造（mod 2 → mod 3，照搬会错）；跳4 再升维（二维差向量 mod 3 + 总量守恒联合判定，问题形态变为可达性 mcq）；跳5 只剩图式（守恒量需自行发现，模数 5 全新，多段式答案，L4）。
>
> 全部答案（含每个照搬错误答案、lure 自身答案）已用 python3 穷举/BFS 独立验证（脚本逻辑记录于各跳 verified）。

## P0（锚点）｜数学·消去游戏

### 题面
黑板上写着 1 到 9 这九个正整数。每步操作：任意擦去两个数 a、b，并写上 |a−b|（结果可为 0，写上的数之后仍可被选用）。反复操作直到黑板上只剩一个数。问最后剩下的数最小可能是多少？

### 解答（显式暴露三步图式）
1. **找不变量**：一步操作把 a+b 换成 |a−b|，总和减少 a+b−|a−b| = 2·min(a,b)，恒为偶数 ⇒ **黑板数字总和的奇偶性在所有允许操作下不变**。
2. **验类别**：初始总和 1+2+…+9 = 45 为奇 ⇒ 任何可达状态总和为奇 ⇒ 终态那个数必为奇数，0 被一票否决。
3. **判可达**：奇类最小候选 1 可构造：(9,8)→1、(7,6)→1、(5,4)→1、(3,2)→1 得 {1,1,1,1,1}；再 (1,1)→0、(1,1)→0、(0,0)→0、(0,1)→1。

**答案：1**（BFS 全枚举可达终值恰为 {1,3,5,7,9}，状态数 2464。）

## 跳1｜MH-B-1｜L1｜P0（数学）→ P1（编码/门禁谜题）

**翻转**：仅 Surface（黑板故事 → 保险库门禁改码器；数集 1..9 → 六个指定缓存值，不变量类别随之从奇翻到偶）。Domain（形式上仍是数学/组合游戏）、Model（|a−b| 消去 + 奇偶不变量）、Method（找不变量→验类别→构造）、Schema 全同。

### P1 题面
一台老式保险库门禁的改码器有 6 个寄存器，当前缓存值为 4、7、9、10、12、14。每按一次组合键，操作员指定两个寄存器：机器将其清空，并把二者之差的绝对值写入一个新寄存器（0 也会被写入，之后仍可参与运算）。反复操作直到只剩一个寄存器，其值即为新的开门码。问开门码最小可设为多少？

### P1 解答
1. 找不变量：同 P0，每次操作总和减 2·min，偶变 ⇒ 缓存总和 mod 2 不变。
2. 验类别：4+7+9+10+12+14 = 56 为偶 ⇒ 终值必为偶数。
3. 判可达：0 可构造——(7,4)→3、(10,3)→7、(9,7)→2、(14,2)→12、(12,12)→**0**。

**答案：0**（numeric）

### 相邻映射（P0→P1）
- 黑板上的数 ↔ 寄存器缓存值；"擦两数写差" ↔ 组合键运算覆写；最后剩下的数 ↔ 开门码；1..9（和 45 奇）↔ {4,7,9,10,12,14}（和 56 偶）。
- 共享关系：两两消去 |a−b|；总和奇偶为不变量；终值类别 = 初始总和 mod 2；类内最小值构造达成。
- 照搬探针：无（近同构，上一跳解法照搬即对——本跳作 TRR 高端锚点）。lure：null（SPEC L1 允许）。

verified：python3 BFS（274 状态）可达终值 {0,2,4,6,8,10,12,14}，min=0；构造路径逐步复核。

## 跳2｜MH-B-2｜L2｜P1（编码谜题）→ P2（化学计量）

**翻转**：Surface + Domain（谜题装置 → 实验室化学计量）；Model/Method 严格同构——"1:1 化学计量比偶联淬灭"剥掉外衣就是 |a−b| 消去，奇偶守恒逐字对应。Schema 同。

### P2 题面
实验室有 5 瓶同种活性单体溶液，所含单体的物质的量分别为 2、5、7、9、12 mmol。把任意两瓶倒入同一反应器时，两瓶中的单体按 1:1 化学计量比发生双分子偶联，生成惰性二聚体沉淀并被滤除；量少的一方耗尽，反应器中剩下 |a−b| mmol 活性单体，作为新的一"瓶"继续参与后续合并。反复合并直到只剩一瓶。问最终一瓶中活性单体最少可剩多少 mmol？

### P2 解答
1. 找不变量：一次偶联消耗两瓶各 min(a,b) mmol，共 2·min(a,b) mmol（偶数）⇒ 体系活性单体总量 mod 2 不变。
2. 验类别：2+5+7+9+12 = 35 为奇 ⇒ 终瓶残留必为奇数，0 mmol 不可达。
3. 判可达：1 可构造——(5,2)→3、(7,3)→4、(12,4)→8、(9,8)→**1**。

**答案：1**（numeric，单位 mmol）

### 相邻映射（P1→P2）
- 寄存器缓存值 ↔ 各瓶单体 mmol 数；组合键取差覆写 ↔ 1:1 偶联淬灭剩 |a−b|；开门码最小 ↔ 终瓶最少残留；和 56（偶类）↔ 和 35（奇类）。
- 共享关系（严格同构）：两两合并消去等量、残差 = |a−b|；总量奇偶不变；类别一票否决 + 类内构造。
- 照搬探针：无（同构，方法照搬即对）。

### lure（同学科·异结构，SPEC L2 规定）
题：瓶 A 含 12 mmol H₂SO₄，瓶 B 含 30 mmol NaOH，混合后按 H₂SO₄ + 2NaOH → Na₂SO₄ + 2H₂O 完全反应，问过量组分剩余多少 mmol？【解答】限量试剂比例：12 mmol 酸需 24 mmol 碱，NaOH 过量，剩 30−24 = **6** mmol。
- 表面相似：同为"两瓶按化学计量比反应、问剩余 mmol"，词汇（mmol、混合、剩余）几乎一致。
- 结构不同：单步限量试剂比例计算，无操作序列、无不变量与可达性判定；把"按比例一次扣减"搬到目标题（多轮自由配对的极值问题）不成立。

verified：python3 BFS（54 状态）可达终值 {1,3,7,11}，min=1；lure 6=30−2×12 复核。

## 跳3｜MH-B-3｜L3｜P2（化学计量）→ P3（分布式系统状态同步）

**翻转**：Surface + Domain + **Model + Method**（操作集实质改变：|a−b| 两两抵消 → 合并求和 + 按 3 清除；不变量必须重造：mod 2 → mod 3）。Schema 同（仍是"守恒类别一票判定终态"）。**照搬上一跳的奇偶不变量会错。**

### P3 题面
某多主数据库集群有 4 个副本，各自积压的未同步写操作数分别为 2、3、4、5。运维只有两种原子操作：
① **反熵合并**：任选两个副本做全量合并，合并后的副本积压数为二者之和（原两个副本合为一个）；
② **快照压缩**：对任一积压数 ≥ 3 的副本执行一次增量快照，恰好固化并清除 3 条积压写操作（该副本积压数减 3）。
要求最终收敛为单一副本。问最终副本的积压数最少可为多少？

### P3 解答（不变量需重造）
1. 找不变量：合并不改变总积压；快照每次使总积压减 3 ⇒ **总积压 mod 3 在所有操作下不变**（注意：奇偶不再守恒——快照一次改变奇偶）。
2. 验类别：2+3+4+5 = 14 ≡ 2 (mod 3) ⇒ 任何终态积压 ≡ 2 (mod 3)，0 与 1 被一票否决。
3. 判可达：2 可构造——四个副本全部合并 → 14，连续快照 4 次 → 14−12 = **2**。

**答案：2**（numeric）

### 相邻映射（P2→P3）
- 瓶 ↔ 副本；单体 mmol 数 ↔ 积压写操作数；"合并"保留但语义反转：偶联抵消（剩 |a−b|）→ 反熵合并（相加，无抵消）；新增操作"快照恰清 3 条"在 P2 无对应物；终瓶残留 ↔ 终副本积压。
- 共享关系（图式级）：操作序列收敛到单元素终态；某守恒量的类别一票判定终态最小值；类内构造达成。
- **照搬探针（错误答案 = 0）**：照搬 P2 的"总量奇偶决定最小残留"——14 为偶 ⇒ 答 0。错在奇偶根本不是本题不变量（快照 −3 翻转奇偶）；真正的守恒量是总和 mod 3，真值 2。

### lure（= 照搬上一跳解法的天真版）
题：只读缓存层有 4 个副本，计数 6、9、10、13。对账操作：任选两副本合为一个，新计数为二者之差的绝对值 |a−b|。收敛为单副本后计数最小是多少？【解答】奇偶不变量：总和 38 偶 ⇒ 终值偶；0 可构造（(13,9)→4、(10,6)→4、(4,4)→0）。答案 **0**。
- 表面相似：同为分布式副本计数收敛为单副本求最小值，术语一致。
- 结构不同：lure 是差量对账（|a−b|，守恒模 2）＝上一跳结构原样换皮；目标题操作集是求和合并+按 3 清除（守恒模 3）。照搬 lure 的奇偶法到目标题得 0，真值 2。

verified：python3 BFS（67 状态）可达终值 {2,5,8,11,14}（全 ≡2 mod 3），min=2，0/1 均不可达（照搬答案 0 证伪）；lure BFS（21 状态）终值 {0,6,8}，min=0。

## 跳4｜MH-B-4｜L3｜P3（分布式系统）→ P4（遗传/生态计量）

**翻转**：Surface + Domain + Model + Method 进一步——操作集再造（−1,−1,+2 的两两转化，总量恒定）；不变量**升维**：单标量"总和 mod 3" → **二维差向量 (橙−蓝, 蓝−黄) mod 3 与总数守恒联合判定**；问题形态从数值极小化变为可达性判定（mcq）。Schema 同。

### P4 题面
某岛屿蜥蜴种群按喉部色型分三类：橙 13 只、蓝 16 只、黄 18 只。行为学观察发现：两只**不同**色型的个体发生领域对峙后，应激激素会使双方都转变为第三种色型（如橙、蓝对峙 → 双方都变黄）；除对峙外色型不变，期间无出生死亡。问经过任意多次对峙后，全种群能否变成同一色型？
A. 只能全橙　B. 只能全蓝　C. 只能全黄　D. 不可能同色

### P4 解答（多守恒量联合）
1. 找不变量：一次对峙使两类各 −1、第三类 +2 ⇒ 任意两类数量之差的变化 ∈ {0, −3, +3} ⇒ **三个两两差 mod 3 全部不变**（二维独立分量，如 (橙−蓝, 蓝−黄) mod 3）；同时总数 47 恒定（每次 −1−1+2 = 0）。
2. 验类别：橙−蓝 = −3 ≡ 0；橙−黄 = −5 ≡ 1；蓝−黄 = −2 ≡ 1 (mod 3)。终态"全 X"要求另外两类同为 0，即那两类之差 ≡ 0 (mod 3)：全黄需要橙≡蓝 ✓；全蓝需要橙≡黄 ✗；全橙需要蓝≡黄 ✗——后两者被一票否决。
3. 判可达：全黄 (0,0,47) 可构造——橙蓝对峙 13 次 → (0,3,44)；蓝黄对峙 1 次 → (2,2,43)；橙蓝对峙 2 次 → (0,0,47)，共 16 步。

**答案：C**（mcq）

### 相邻映射（P3→P4）
- 副本 ↔ 色型类群；积压数 ↔ 各色型个体数；"合并+清除"操作集 ↔ "对峙双转第三型"操作集（全新）；单守恒量 总和 mod 3 ↔ 二维守恒量 差向量 mod 3 + 总数守恒；"终态最小值" ↔ "指定终态可达性（mcq）"。
- 共享关系（图式级）：允许操作保持某守恒结构；目标终态的不变量类别与初态不符即一票否决；类别相符时再给构造。
- **照搬探针（错误答案 = D）**：照搬 P3 的"总和 mod 3 判终态"——总数 47 ≡ 2 (mod 3) ≠ 0 ⇒ 天真判"不可能同色"选 D。错在本题对峙不改变总数（总和 mod 3 平凡守恒、不含判别信息），真正的判别量是两两差 mod 3；真值 C。

### lure（= 照搬上一跳解法的天真版）
题：滨海保护区 3 个蜥蜴栖息斑块个体数 5、7、9。管理操作：① 并巢：两个斑块合并、个体数相加；② 一次风暴使某个体数 ≥ 3 的斑块恰好折损 3 只。最终并为单一斑块，问斑块个体数最少几只？【解答】总数 mod 3 不变：5+7+9 = 21 ≡ 0 ⇒ 最少 **0**（先并成 21，再折损 7 次）。
- 表面相似：同为蜥蜴种群三个群体、同问终态。
- 结构不同：lure 是 P3 结构的生态换皮（守恒量 = 总数 mod 3）；目标题总数恒定、判别靠二维差向量 mod 3。照搬 lure 方法到目标题（47≡2 ⇒ 不可能）得 D，真值 C。

verified：python3 BFS（392 状态，总数 47 守恒）唯一可达单色态 = (0,0,47) 全黄 ⇒ C；全橙/全蓝不可达（差 ≡1 mod 3 证伪 + BFS 枚举双证）；照搬答案 D 证伪；lure BFS（67 状态）min=0。

## 跳5｜MH-B-5｜L4｜P4（生态计量）→ P5（货币/资产兑换）

**翻转**：除 Schema 外全翻——二资产（非三类）、铸销操作使总量每步 +3（总量不守恒）、守恒量的存在与形式都不再给出任何提示：**必须自己从操作的净变化 (−1,+4)/(+4,−1) 中发现"差 mod 5"这一全新守恒量**；答案多段式（判定;数值）防蒙对。仅共享"操作保持的不变量一票判定可达性"图式。

### P5 题面
某离岸清算所内部流通两种记账凭证：晶片券 C 与条纹券 B（张数均为非负整数）。清算规则只允许两种操作、次数不限：
① 销毁 1 张 C，同时增发 4 张 B（要求当前 C ≥ 1）；
② 销毁 1 张 B，同时增发 4 张 C（要求当前 B ≥ 1）。
某做市商期初持有 C = 3 张、B = 0 张。监管注销条款要求两种凭证持仓完全对等（C = B）时方可整体注销。问：(a) 该做市商能否达到 C = B？(b) 若不能，|C − B| 最小可压到多少？答案格式："能;0" 或 "否;最小差额"。

### P5 解答（守恒量需自行发现）
1. 找不变量：操作① 使 C−B 变化 −1−4 = −5；操作② 使 C−B 变化 +4+1 = +5 ⇒ **C−B mod 5 在所有操作下不变**（注意总张数每步 +3，不守恒；两张数各自也不守恒——唯一的守恒结构要从净变化量里挖出来）。
2. 验类别：期初 C−B = 3 ⇒ 恒有 C−B ≡ 3 (mod 5)。C = B 要求差为 0 ≢ 3——一票否决，(a) 答"否"。
3. 判可达：可能的差值 ∈ {…, −7, −2, 3, 8, …} ⇒ |C−B| 最小候选为 2（差 = −2 ≡ 3 mod 5）。构造：期初执行一次操作① → (C,B) = (2,4)，|C−B| = **2**。

**答案：否;2**（string，分号分隔两段）

### 相邻映射（P4→P5）

### lure（= 照搬上一跳解法的天真版）
