# AR 管线法构造 case（Analogical Reasoning 两步法）

> 构造方法研究产物。方法：Shen et al. 2026 两步管线——步骤1 从源题显式抽取对象集 O_p 与关系集 R_p；步骤2 生成远域类比（对象映射表 M + 共享关系子集 R_a）；步骤3 将类比实例化为机器可判的目标题；步骤4 python3 独立验证。中间产物全部保留，方法过程可见。
> 学科对（均避开题库已用对）：语言学↔音乐和声、社会网络↔建筑结构、运动生理（体育竞技）↔供暖工程。

## Case 1：L2-A-AR1 ｜ A-约束枚举 ｜ 语言学 → 音乐和声

图式：带类型的相邻转移约束切割序列空间——按状态分类做加权递推（转移矩阵）计数，末端状态限制须单独处理。

### 【步骤1 抽取结果】

源题（语言学，音系学/组合计数，竞赛级）：

> 田野调查记录到一种语言，其音位分三类：辅音 C = {p, t, k, s}（4 个）、元音 V = {a, i, u}（3 个）、滑音 G = {w, j}（2 个）。该语言的合法词满足两条音系规则：(i) 两个元音不能相邻；(ii) 滑音之后必须紧跟一个元音（因此滑音不能出现在词尾）。词可以以任何一类音位开头。问：长度恰为 6 个音位的合法词共有多少个？

源解答（算子序列）：设 f_n(X) 为长度 n、末位属类 X 的合法前缀加权数。转移规则：C→{C,V,G}，V→{C,G}（禁 VV），G→{V}（规则 ii）。初始 f_1 = (C:4, V:3, G:2)；每步 f_{n+1}(Y) = Σ_{X→Y 允许} f_n(X)·|Y|。递推 5 步后求 f_6(C)+f_6(V)（G 不能收尾）。逐步：f_2=(C:28, V:18, G:14)，f_3=(C:184, V:126, G:92)，f_4=(C:1240, V:828, G:620)，f_5=(C:8272, V:5580, G:4136)，f_6=(C:55408, V:37224, G:27704)。答案 = 55408+37224 = **92632**。

抽取的对象集 O_p：
- o1 音位类别 {C, V, G}（带类别容量 4/3/2）
- o2 类内具体音位（同类可互换，只贡献乘法权重）
- o3 定长序列（词，长度 6）
- o4 相邻位置对（转移）
- o5 序列末端位置

抽取的关系集 R_p：
- r1 类型化转移约束：允许转移构成一张有向图 C→{C,V,G}, V→{C,G}, G→{V}
- r2 权重可分解：序列计数 = 合法类别串数 × ∏(各位置类别容量)，即加权转移矩阵
- r3 末端吸收限制：某类（G）因"其后必须接 X"而被禁止收尾，须在求和时剔除
- r4 最优子结构：按"末位类别"分状态的线性递推完整刻画约束（马尔可夫性）
- r5 起始自由：首位无约束，初值 = 类别容量

### 【步骤2 类比表】

远域选择：音乐和声（功能和声写作练习）。理由：功能和声天然具有"类型化转移语法"（属功能必须解决到主功能），与音系配位法同构，且题库无语言学、无音乐和声域。

对象映射表 M：

| 源（语言学） | 目标（音乐和声） |
| --- | --- |
| 音位类别 C（辅音，4 个） | 下属功能类 S（IV, ii, ii6, ii7，4 个）→ 目标改为容量 4 |
| 音位类别 V（元音，3 个） | 主功能类 T（I, I6, vi，3 个） |
| 音位类别 G（滑音，2 个） | 属功能类 D（V, V7，2 个） |
| 词（长度 6） | 和弦进行（长度 7，surface 参数改写） |
| 规则"禁 VV" | 规则"主功能不得连用（禁 T→T）" |
| 规则"G 后必须接 V" | 规则"属功能之后必须解决到主功能（D→T）" |
| "滑音不能收尾" | "进行不得终止于属和弦" |
| 词首自由 | 进行可从任何功能开始 |

共享关系子集 R_a = {r1 类型化转移图（同构：S↔C, T↔V, D↔G 下逐边对应）, r2 加权可分解, r3 末端吸收限制, r4 按末位类别的线性递推, r5 起始自由}——R_a = R_p 全集，故为 L2 跨科同构。

翻转成分：Surface（音位→和弦、全部数值：长度 6→7）、Domain（语言学→音乐理论）；Model / Method / Schema 保持。

### 【步骤3 题面 + 解答】

目标题（音乐和声）：

> 某和声学教材的写作练习给出 9 个可用和弦，按功能分三类：下属功能 S = {IV, ii, ii6, ii7}（4 个）、主功能 T = {I, I6, vi}（3 个）、属功能 D = {V, V7}（2 个）。练习规则：(i) 主功能和弦不得连续使用（相邻两拍不能都取 T 类）；(ii) 属功能和弦之后必须紧接一个主功能和弦（因此属和弦不能作为最后一拍）。进行可以从任何功能开始，同一和弦可重复选用。问：长度恰为 7 拍的合法和弦进行共有多少种？

目标解答：同构递推，状态 = 末拍功能类。转移：S→{S,T,D}，T→{S,D}，D→{T}；权重 = 类容量 (4,3,2)；初值 (S:4, T:3, D:2)；递推 6 步，答案 = f_7(S)+f_7(T)（剔除 D 收尾）= **619864**。

目标答案：619864（numeric，精确整数）。冷启动难度自评 ~40–55%：7 步三状态加权递推 + 禁尾剔除，思路可得但算术链长、"D 不能收尾"易漏。

lure（L2 约定：同学科异结构，音乐皮）：

> 即兴课练习：从 9 个不同和弦中每拍任选一个写出 7 拍的进行，唯一要求是相邻两拍不能用同一个和弦。共有多少种写法？（答案 9×8^6 = 2 359 296。）

- 表面相似：同为"9 个和弦、7 拍、相邻约束"的和弦进行计数，数字全部相同。
- 结构不同：约束是均匀的"个体互异"（无类型结构、无吸收性规则、无禁尾），k(k−1)^{n−1} 一步闭式即可；把该公式照搬到目标题得 2 359 296，真值 619864。

### 【步骤4 验证】

python3 双路验证（scratchpad/verify_ar.py）：源题 brute-force 枚举全部 3^6 个类别串逐条检查规则并累乘权重 = 92632，与转移矩阵 DP 一致；目标题枚举 3^7 = 619864，与 DP 一致；lure 闭式 9·8^6 = 2359296。断言全部通过。

## Case 2：L3-B-AR2 ｜ B-不变量验证 ｜ 社会网络 → 建筑结构

图式：局部阈值触发的状态沿网络邻接单调、不可逆地级联传播至不动点；终态由初始扰动位置与各节点局部承受力共同决定。

### 【步骤1 抽取结果】

源题（社会网络，传播动力学，竞赛级）：

> 某校园社交网络有 9 名用户 A–I，好友关系（无向边）为：A–B, A–C, B–C, A–D, B–D, C–E, D–E, D–F, E–F, E–G, F–G, G–H, H–I, F–I。第 0 天，A 和 B 因内测邀请安装了某新 App。此后每天同步更新一次：尚未安装的用户如果发现自己的好友中已有至少 2 人安装，当天就会安装（安装后不再卸载）。传播停止后，最终共有多少名用户安装了该 App？

源解答（算子序列）：同步轮次模拟到不动点。第 1 轮：C（好友 A,B 已装）、D（A,B）安装；第 2 轮：E（C,D）；第 3 轮：F（D,E）；第 4 轮：G（E,F）；第 5 轮无新增——H 只有 1 个已装好友 G，I 只有 F，均达不到阈值 2，级联在 G 处止步。最终安装者 {A,B,C,D,E,F,G}，共 **7** 人。

抽取的对象集 O_p：
- o1 节点（用户）
- o2 无向邻接边（好友关系）
- o3 二元状态（已装/未装），单调不可逆
- o4 初始种子集 {A, B}
- o5 局部触发条件（已装好友数 ≥ 2）
- o6 不动点终态

抽取的关系集 R_p：
- r1 状态只沿邻接边影响邻居（局部性）
- r2 状态转移单调不可逆（激活后永不回退）
- r3 触发条件是对邻居状态的局部聚合量与阈值的比较
- r4 同步迭代必达不动点（单调性保证收敛）
- r5 终态规模由"种子位置 × 网络结构 × 局部阈值"共同决定，边缘低连通节点截断级联

### 【步骤2 类比表】

远域选择：建筑结构工程（连锁倒塌 / progressive collapse）。理由：构件失效沿共承关系传播与社交采纳级联共享同一"阈值级联到不动点"图式，但触发条件从布尔计数变为守恒载荷量的重分配——天然构成 L3 的"近同构 + 照搬会错"。

对象映射表 M：

| 源（社会网络） | 目标（建筑结构） |
| --- | --- |
| 用户 | 桁架构件（梁） |
| 好友边 | 共承邻接（相邻共同分担载荷的构件对） |
| "已安装"状态 | "已失效"状态（同为单调不可逆） |
| 种子安装者 {A,B} | 初始失效构件 M1（焊缝断裂） |
| 触发条件"已装好友数 ≥ 2" | 触发条件"累计载荷 > 承载力"（布尔计数 → 守恒量比较，Model 翻转点） |
| 每轮同步更新 | 每步同时失效并重分配 |
| 传播停止（不动点） | 连锁倒塌止损（不动点） |

共享关系子集 R_a = {r1 局部性, r2 单调不可逆, r4 迭代至不动点, r5 终态由初始扰动+网络结构+局部承受力决定}；不保持的关系：r3 的聚合量语义——从"邻居状态计数"变为"守恒载荷量沿边流动累加"（失效构件的载荷必须按份额转移，总载荷守恒——线程 B 的守恒量视角）。

翻转成分：Surface、Domain 翻转；Model 近同构（同为图上单调级联至不动点，但触发从布尔阈值→数量守恒阈值，出现"载荷份额取决于失效时刻的完好邻居数"这一新耦合）；Method 需适配（数邻居 → 逐步簿记载荷、均分重分配、与各自承载力比较）；Schema 保持。

### 【步骤3 题面 + 解答】

目标题（建筑结构）：

> 某人行廊桥的一侧桁架由 7 根主要受力构件 M1–M7 组成，共承邻接关系（相邻构件共同分担载荷）为：M1–M2, M1–M3, M2–M3, M2–M4, M3–M5, M4–M5, M4–M6, M5–M7, M6–M7。当前各构件承担载荷（kN）：M1=16, M2=10, M3=10, M4=8, M5=8, M6=6, M7=6；剩余承载力上限（kN）：M2=28, M3=17, M4=26, M5=15, M6=22, M7=13。检修中发现 M1 焊缝完全断裂、瞬间退出工作。失效规则：构件失效时，其失效时刻承担的全部载荷平均分给与它相邻且仍完好的构件；任何构件一旦累计载荷严格超过其承载力上限即告失效（恰好等于不失效）；同一步中所有超载构件同时失效再重分配；失效构件若无完好邻居，其载荷由支座直接承担、不再传递。问：连锁传播停止后，共有多少根构件失效（含 M1）？

目标解答：逐步簿记。M1(16) 失效 → M2、M3 各 +8：M2=18≤28 存活，M3=18>17 失效；M3(18) → 完好邻居 {M2,M5} 各 +9：M2=27≤28 存活（仅差 1 kN！），M5=17>15 失效；M5(17) → 完好邻居 {M4,M7} 各 +8.5：M4=16.5≤26 存活，M7=14.5>13 失效；M7(14.5) → 完好邻居 {M6} +14.5：M6=20.5≤22 存活，级联止。失效集 {M1,M3,M5,M7}——沿单侧弦杆锯齿形传播。答案：**4**（numeric）。冷启动难度自评 ~35–55%：需精确追踪份额（M2 以 1 kN 之差存活、M6 以 1.5 kN 之差存活，粗算即错）。

照搬为什么错（L3 负迁移探针）：照搬源题的布尔计数阈值（"相邻构件中已有 ≥2 根失效则本构件失效"）——初始只有 M1 失效，任何构件都凑不齐 2 个失效邻居，结论"级联不发生"，错误答案 = **1**；真值 4。错在把"守恒量沿边流动累加"降级成了"邻居状态计数"：这里 1 个高载邻居的份额就足以压垮 M3，而 2 个失效邻居也未必压垮 M4。

lure（L3 约定：源解法的天真照搬版）：

> 同一座廊桥做缺陷排查，验收规则规定：若一根构件的相邻构件中已有至少 2 根被标记为"待复检"，则该构件也须标记。初始只有 M1 被标记，问最终共有多少根构件被标记？（布尔规则下答案 1。）

- 表面相似：同一桁架、同一邻接表、同为"状态沿相邻构件传播到停止"。
- 结构不同：标记规则是纯布尔计数、无载荷量流动；其解法（数失效邻居）照搬到目标题得 1，真值 4。

### 【步骤4 验证】

python3 模拟（scratchpad/verify_ar.py）：源题同步级联 4 轮新增 {C,D}→{E}→{F}→{G} 后停止，最终 7 人，H/I 均只有 1 个已装好友，断言通过；目标题逐步重分配模拟，失效序列 M1→M3→M5→M7，幸存者终载 M2=27.0/28、M4=16.5/26、M6=20.5/22 均不超限，失效总数 4；布尔照搬版模拟 = 1。断言全部通过。

## Case 3：L4-D-AR3 ｜ D-元认知控制 ｜ 运动生理（体育竞技） → 供暖工程

图式：需求超过可持续供给能力并不意味着立即不可行——有限缓冲储备以净亏空速率被透支，"是否行动/追加资源"的决策由缓冲可撑的时间窗与超载持续的地平线之比较决定，而非由峰值对比决定。

### 【步骤1 抽取结果】

源题（运动生理 / 自行车竞技，临界功率模型，竞赛级）：

> 一名场地自行车手的临界功率 CP = 280 W（可无限期维持），无氧做功储备 W′ = 21.6 kJ。输出功率 P 高于 CP 时，储备以 (P − CP) J/s 的速率消耗；低于 CP 时以 (CP − P) J/s 的速率恢复（不超过 21.6 kJ 上限）；储备耗尽即力竭。比赛前两段已骑完：第 1 段突围 5 分钟、平均 340 W；第 2 段跟车 10 分钟、平均 260 W。现在进入最后爬坡，教练要求以 350 W 再维持 4 分钟完成超越。(a) 该配速方案可行吗（可行/不可行）？(b) 力竭前该车手在 350 W 下最多还能维持多少秒（1 位小数）？

源解答（算子序列，显式体现图式）：分段簿记储备。段 1：消耗 (340−280)×300 = 18 kJ，W′ = 3.6 kJ；段 2：恢复 (280−260)×600 = 12 kJ，W′ = 15.6 kJ（未触及上限）；段 3：净耗率 350−280 = 70 J/s，可撑时间 = 15600/70 = 222.9 s ≈ 3.71 min < 4 min。关键认知步：340 W、350 W 都远超"可持续能力"280 W，但这不直接判死——可行性取决于剩余储备除以净耗率得到的时间窗与任务地平线（4 min）的比较。答案：**不可行;222.9**。

抽取的对象集 O_p：
- o1 可持续供给速率（CP = 280 W）
- o2 有限缓冲储备（W′，容量 21.6 kJ，有上限）
- o3 时变需求（各赛段功率）
- o4 净亏空/净盈余速率（P − CP 的符号与大小）
- o5 硬下限（储备 = 0 即力竭）
- o6 任务地平线（教练要求的 4 分钟）

抽取的关系集 R_p：
- r1 超出可持续速率的需求只能靠缓冲透支，缓冲变化率 = 供给 − 需求（存量-流量关系）
- r2 峰值需求 > 可持续供给 ≠ 不可行：可行性由"缓冲/净亏空速率"给出的时间窗决定
- r3 可持续期（低载）为缓冲充电，历史轨迹通过缓冲余量影响未来可行性
- r4 决策算子：比较"可撑时间窗"与"超载地平线"，二者相对大小翻转结论
- r5 缓冲有硬边界（满充上限、耗尽下限）

### 【步骤2 类比表】

远域选择：供暖工程（建筑热惰性与锅炉容量决策）。理由：建筑热容对锅炉的意义与 W′ 对运动员完全同构于图式层——但热缓冲的透支动力学是一阶 RC（损耗随室温下降自行缓解），与线性水库模型（净耗率恒定）在 Model 与 Method 上全面翻转，构成 L4 远类比。

对象映射表 M：

| 源（运动生理） | 目标（供暖工程） |
| --- | --- |
| 临界功率 CP = 280 W | 锅炉持续最大出力 200 kW |
| 无氧储备 W′ = 21.6 kJ | 建筑蓄热缓冲 C×ΔT_允许 = 800 MJ/K × 3 K = 2.4 GJ |
| 赛段需求功率 | 寒潮期热损耗 U(T_in − T_out) |
| 净耗率 P − CP（恒定） | 净亏空 U(T−T_out) − P（随 T 下降自行缩小——Model 翻转点） |
| 力竭（储备耗尽） | 室温跌破舒适下限 18 °C |
| 教练要求的 4 分钟 | 寒潮持续的 10 小时（地平线） |
| "可行吗" | "须临时增租移动锅炉吗" |

共享关系子集 R_a = {r1 存量-流量透支, r2 峰值超载≠不可行、可行性由时间窗决定, r4 时间窗 vs 地平线的比较决策, r5 缓冲硬边界}；不保持的关系：r3 的"恒定净耗率"——目标域净亏空随室温下降递减，甚至存在平衡温度 T_eq = T_out + P/U，若 T_eq ≥ 下限则缓冲永不耗尽（源域无此结构）。

翻转成分：Surface、Domain、Model（分段线性水库带上限 → 一阶 RC 热网络，需先判 T_eq 再解指数轨迹）、Method（算术簿记除法 → 建立 dT/dt 方程、解 t = (C/U)·ln[(T_0−T_eq)/(T_min−T_eq)]）全部翻转；仅 Schema 保持。对象映射非平凡（"储备"在目标域不是显式给的量，而是 热容×容许温降 的乘积；"净耗率恒定"这一源域直觉必须主动放弃）。

### 【步骤3 题面 + 解答】

目标题（供暖工程）：

> 某学校教学楼由一台持续最大出力 200 kW 的燃气锅炉供暖。楼体综合传热系数 U = 6.5 kW/K（热损耗 = U × 室内外温差），有效热容 C = 800 MJ/K。气象预警：今夜将有一股寒潮，室外温度骤降至 −19 °C 并维持 10 小时，之后回暖。寒潮抵达时室内为 21 °C；校方规定室温不得低于 18 °C，否则必须停课。假设锅炉全程满负荷运行。(a) 校方是否必须在寒潮前临时增租移动锅炉（需/不需）？(b) 若不增租，室温从 21 °C 降到 18 °C 需要多少小时（1 位小数）？

目标解答（显式体现图式）：①峰值对照：−19 °C 时若维持 21 °C，损耗 = 6.5×40 = 260 kW > 200 kW——静态看"锅炉不够"，但这不直接判死；②先判平衡温度：T_eq = −19 + 200/6.5 = 11.77 °C < 18 °C，说明缓冲终将被透支、确实存在有限时间窗；③解一阶 RC 轨迹 C·dT/dt = P − U(T−T_out)：t = (C/U)·ln[(21−T_eq)/(18−T_eq)] = 123077 × ln(9.231/6.231) = 48374 s ≈ 13.4 h；④决策：时间窗 13.4 h > 寒潮地平线 10 h，热惰性足以硬扛，无须增租。答案：**不需;13.4**（string；数值段 tolerance ±0.2）。冷启动难度自评 ~25–45%：需自行识别"热容即缓冲储备"、判 T_eq、解对数式；常见错误"恒定净亏空 60 kW 线性近似"得 2.4 GJ/60 kW = 11.1 h（仍 >10 但数值段判错），静态峰值法直接答"需"（决策段判错）——两段式答案分别拦截两类失败。

lure（L4 约定：同域异图式，供暖皮）：

> 同一栋教学楼做供暖系统选型：设计室内温度 21 °C、冬季设计室外温度 −19 °C、U = 6.5 kW/K，按规范设计热负荷需另加 10% 安全裕量。应选用额定出力至少多少 kW 的锅炉？（稳态法：6.5×40×1.1 = 286 kW。）

- 表面相似：同一栋楼、同一批参数（U、温差、锅炉容量），同样在问"锅炉够不够/该多大"。
- 结构不同：稳态选型是无时间维度的峰值流量匹配，不含缓冲储备与地平线概念；照搬 lure 思路到目标题即"260 kW > 200 kW ⇒ 需增租"，恰好在 (a) 段答错。

### 【步骤4 验证】

python3 复算（scratchpad/verify_ar.py）：源题分段簿记 W′ = 21.6→3.6→15.6 kJ（未触充电上限），222.9 s < 240 s，"不可行"成立；目标题 T_eq = 11.77 °C < 18 °C（时间窗有限性成立），t = 48374 s = 13.44 h > 10 h，"不需"成立；错误线性近似 11.11 h 与真值 13.4 h 在 ±0.2 容差下可区分；lure 稳态法 286 kW 导致误判"需增租"。断言全部通过。

## 构造小记（AR 管线法体验）

- 顺：步骤1 的 O_p/R_p 显式化之后，步骤2 几乎是"按关系集找宿主域"的检索问题，远域候选一出现（功能和声的转移语法、连锁倒塌的级联、热惰性的缓冲），映射表可以机械地逐行填完，L2 的同构性检查（R_a 是否 = R_p）也变成逐条勾选。
- 卡：两处。一是 L3/L4 的"该丢哪条关系"需要反复试——丢错关系（如 Case 2 若丢局部性而非阈值语义）会退化成 L4 或造不出"照搬会错"的探针；二是步骤3 的参数标定占了最多迭代（Case 2 调了两轮载荷/承载力才让级联在 M6 前恰好止步、M2 以 1 kN 幸存），管线不替你管数值净空。
- 副产品：显式 R_p 让 lure 设计变容易——lure 就是"保 Surface、换掉 R_p 中最核心那条关系"的反向实例化。
