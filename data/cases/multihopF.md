# 多跳长链 F-multihop-01（线程 F-逆问题）

> 与 chainA/chainE 的区别：那两条链是"源固定、只有目标动"；本链是**连环迁移**——同一抽象图式在 P0→P1→P2→P3→P4→P5 六个节点间接力，**每跳的源题是上一跳的题**，学科每跳都换。测的是迁移的传递性：在 Pi→Pi+1 学到的映射能否接力到下一跳。
>
> 固定图式 Schema："隐藏组成无法直接观测，但每条加权观测（各成分按不同权重贡献一个可测总量）都给出一条关于组成的线性约束，多条观测联立即可反演组成。"解法三步式：**设组成 → 列观测方程 → 联立反演**。
>
> 结构距离逐跳升级：跳1 仅翻 Surface（严格同构，系数矩阵同为 (1,1)/(2,4) 型）；跳2 跨科仍严格同构（两未知两观测闭式消元）；跳3 未知数比观测多一个——欠定系统须靠整数/非负约束丢番图筛解，照搬"方形消元解唯一解"会错；跳4 观测反而冗余且含一条坏数据——须先做一致性检验（多数票）识别并剔除坏观测再反演，照搬"所有观测都可信、抓两条直接消元"会错；跳5 只剩图式（L4）——载体全新（稳定同位素混合模型/来源解析），题面无"方程/联立"等提示词，闭合约束（占比和为 1）须自行补上，答案多段式。
>
> **题面去脚手架**（对齐试点报告修订建议）：所有目标题只陈述可观测事实（数出的头/轮子、称出的质量、点出的张数、化验单读数、同位素比值），不出现"设未知数""列方程""联立"等方法提示，也不给现成公式。
>
> 全部答案（含每个照搬错误答案、lure 自身答案）已用 python3 独立验证（穷举/分数精确算术/线性代数，逻辑记录于各跳 verified）。

## P0（锚点）｜数学·算术趣题（鸡兔同笼，非教科书参数）

### 题面
农妇的院子里圈养着鸡和兔。她从栅栏外数得头共 47 个，脚共 128 只。问兔有多少只？

### 解答（显式暴露三步图式）
1. **设组成**：院子里的"组成"（鸡 x 只、兔 y 只）无法直接看清，设为未知量。
2. **列观测方程**：每条可观测总量都是组成的加权和——头数观测：每只动物贡献 1 个头，x + y = 47；脚数观测：鸡贡献 2、兔贡献 4，2x + 4y = 128。
3. **联立反演**：第一式 ×2 与第二式相减，2y = 128 − 2×47 = 34 ⇒ y = 17，x = 30。

**答案：17**（穷举 47×47 组合唯一解 (鸡30, 兔17)；教科书经典参数为 35 头 94 脚，此处已换参。）

## 跳1｜MH-F-1｜L1｜P0（算术趣题）→ P1（场务管理/交通清点）

**翻转**：仅 Surface（鸡兔 → 摩托车与汽车；头/脚 → 车辆数/轮子数；47/128 → 63/208）。Domain（形式上仍是数学应用题）、Model（系数矩阵 (1,1)/(2,4) 逐字同构）、Method（×2 相减消元）、Schema 全同。

### P1 题面
物业管理员巡查地下停车场，场内只停着摩托车和汽车。她逐一清点，共数得车辆 63 辆；又低头数轮子，共 208 个（每辆车轮子齐全，无备胎落地）。问场内有多少辆汽车？

### P1 解答
1. 设组成：摩托车 m 辆、汽车 c 辆。
2. 列观测方程：车辆数 m + c = 63；轮子数 2m + 4c = 208。
3. 联立反演：2c = 208 − 2×63 = 82 ⇒ c = 41（m = 22）。

**答案：41**（numeric）

### 相邻映射（P0→P1）
- 鸡 ↔ 摩托车（低权重成分，权重 2）；兔 ↔ 汽车（高权重成分，权重 4）；头数观测 ↔ 车辆数观测（权重 1,1）；脚数观测 ↔ 轮子数观测（权重 2,4）；47/128 ↔ 63/208。
- 共享关系：隐藏组成二元；两条加权线性观测；系数矩阵同构；消元次序逐步对应。
- 照搬探针：无（严格同构，上一跳解法照搬即对——本跳作 TRR 高端锚点）。lure：null（SPEC L1 允许）。

verified：python3 穷举 64×64 组合唯一解 (22, 41)；消元公式 (208−2×63)/2 = 41 复核。

## 跳2｜MH-F-2｜L2｜P1（交通清点）→ P2（考古材料学）

**翻转**：Surface + Domain（停车场 → 青铜器实验室）；Model/Method 严格同构——两未知（铜、锡体积）两观测（总体积、总质量），"密度"就是"每单位体积的质量权重"，剥掉外衣与"每辆车的轮子数"同一角色。Schema 同。

### P2 题面
考古队清理出一件青铜礼器残件，检测认定其为铜锡二元合金、内部致密无空腔。实验室称得残件质量 413 g；排水法测得体积 50 cm³。已知纯铜密度 8.9 g/cm³、纯锡密度 7.3 g/cm³，且合金体积可按两金属体积简单相加。问残件中含锡多少克？

### P2 解答
1. 设组成：铜体积 u cm³、锡体积 v cm³。
2. 列观测方程：体积观测 u + v = 50（权重 1,1）；质量观测 8.9u + 7.3v = 413（权重 = 各自密度）。
3. 联立反演：8.9×50 − 413 = 32 = (8.9−7.3)v ⇒ v = 20 cm³ ⇒ 锡质量 = 20 × 7.3 = 146 g。

**答案：146**（numeric，单位 g；铜 30 cm³=267 g 复核 267+146=413 ✓）

### 相邻映射（P1→P2）
- 摩托车/汽车 ↔ 铜/锡（两成分）；车辆数观测 ↔ 总体积观测（等权计数）；轮子数观测 ↔ 总质量观测（"每辆轮子数" ↔ "每 cm³ 克数"=密度）；63/208 ↔ 50/413。
- 共享关系（严格同构）：二元隐藏组成；等权观测 + 差异权重观测各一条；闭式消元 (高权×总量−实测)/(权差)；解唯一。
- 照搬探针：无（同构，方法照搬即对）。

### lure（同学科·异结构，SPEC L2 规定）
题：博物馆送检一尊号称纯铜实心的坐像，称重 445 g，排水法测体积 55 cm³。纯铜密度 8.9 g/cm³。若质量属实，坐像内部空腔有多大？【解答】实心纯铜应占 445/8.9 = 50 cm³，空腔 = 55 − 50 = **5** cm³。
- 表面相似：同为文物、称重+排水、同一批词汇（密度、cm³、纯铜 8.9）。
- 结构不同：单未知单步除法+差值，没有"两成分组成反演"结构；把"总量÷密度再作差"照搬到二元合金题上无从下手（不存在单一密度可除）。

verified：python3 分数精确算术：v_Sn = (8.9×50−413)/(8.9−7.3) = 20，锡 20×7.3 = 146；lure 55−445/8.9 = 5.0。

## 跳3｜MH-F-3｜L3｜P2（考古材料学）→ P3（金融/现金核算）

**翻转**：Surface + Domain + **Model + Method**（未知数 3 个 > 观测 2 条：系统欠定，"方形消元出唯一解"失效；须消元到一条丢番图方程，再用**整数+非负约束**筛出唯一解）。Schema 同（仍是"加权观测联立反演组成"）。**照搬上一跳的两未知闭式消元会错。**

### P3 题面
自动售货机的找零硬币仓混装着 10 美分、25 美分、50 美分三种硬币。运维员倒出全部硬币清点：共 16 枚；投入点钞机称总额，读数 5.15 美元。问三种硬币各有几枚？（按面额从小到大，答案格式如 "a;b;c"）

### P3 解答（欠定 → 丢番图筛）
1. 设组成：10¢ x 枚、25¢ y 枚、50¢ z 枚。
2. 列观测方程：枚数 x + y + z = 16；总额 10x + 25y + 50z = 515。**两条观测、三个未知——直接消元无唯一解。**
3. 联立+约束筛：总额式 ÷5 减 2×枚数式得 3y + 8z = 71。整数约束：71 − 8z ≡ 0 (mod 3) ⇒ z ≡ 1 (mod 3) ⇒ z ∈ {1, 4, 7}；非负约束逐一验：z=1 ⇒ y=21 ⇒ x=−6 ✗；z=4 ⇒ y=13 ⇒ x=−1 ✗；z=7 ⇒ y=5 ⇒ x=4 ✓。唯一解 (4, 5, 7)。

**答案：4;5;7**（string；核验 4+5+7=16、40+125+350=515 ✓）

### 相邻映射（P2→P3）
- 铜/锡 ↔ 三种面额硬币（成分基数 2→3）；总体积观测 ↔ 总枚数观测；总质量观测（密度加权）↔ 总金额观测（面额加权）；"密度" ↔ "面额"。
- 共享关系（图式级）：隐藏组成、每条观测=组成的加权和、联立反演；新增结构：约束数 < 未知数，解唯一性由整数/非负性恢复。
- **照搬探针（错误答案 = 7;0;9）**：照搬 P2 的"两未知两观测方形消元"——最常见落法是砍掉中间面额（设 25¢ 为 0 枚）硬凑方形：x + z = 16、10x + 50z = 515 ⇒ z = 355/40 = 8.875 非整数，四舍五入报 (7, 0, 9)；核验总额 70+450 = 520 ≠ 515，错。错在系统本就欠定，唯一性来自整数筛而非砍未知数；真值 4;5;7。

### lure（= 照搬上一跳解法的天真版）
题：另一台咖啡机的硬币仓只收 5 美分和 25 美分两种硬币，清点共 21 枚、总额 3.05 美元。两种各几枚？【解答】方形消元：25×21 − 305 = 220 = 20×(5¢ 枚数) ⇒ 5¢ 共 **11** 枚、25¢ 共 10 枚（55+250=305 ✓）。
- 表面相似：同为售货机硬币仓清点、同一批词汇（枚数、总额、美分）。
- 结构不同：lure 是两未知两观测的方形系统（＝上一跳结构的金融换皮），闭式消元即唯一解；目标题三未知欠定，照搬 lure 的消元模板正好落进 "7;0;9" 探针。

verified：python3 穷举 17³ 组合唯一解 (4,5,7)；筛解路径 z∈{1,4,7} 仅 z=7 非负，断言通过；照搬 z=8.875、取整后总额 520≠515 证伪；lure 消元 11/10 复核。

## 跳4｜MH-F-4｜L3｜P3（现金核算）→ P4（食品营养检验）

**翻转**：Surface + Domain + Model + Method 再变——观测从"不够用"（欠定）反转为"**多且脏**"：4 条观测对 2 个未知（超定），其中 1 条来自失准仪器。直接联立必被坏数据带偏；须先**成对反演做一致性检验（多数票）**识别坏观测、剔除后再反演。Schema 同。**照搬上一跳"每条观测都是可信约束、拿来就联立"会错。**

### P4 题面
质检站抽检一袋 200 g 的二元混合代餐粉，配料只有大豆粉和燕麦粉。成分表载明：每 100 g 大豆粉含蛋白质 36 g、脂肪 20 g、碳水 30 g；每 100 g 燕麦粉含蛋白质 13 g、脂肪 7 g、碳水 68 g。化验室的三个独立检测模块给出这袋粉的实测值：蛋白质 60.5 g、脂肪 29.6 g、碳水 90.4 g。事后质控通报：三个模块中有一个当天校准失效、读数不可信，但通报未注明是哪一个。问这袋粉中大豆粉有多少克？

### P4 解答（先一致性检验剔坏数据，再反演）
1. 设组成：大豆粉 s g、燕麦粉 200 − s g。
2. 列观测方程（每条化验读数各给一条加权约束）：蛋白 0.36s + 0.13(200−s) = 60.5；脂肪 0.20s + 0.07(200−s) = 29.6；碳水 0.30s + 0.68(200−s) = 90.4。
3. 一致性检验（多数票）：三条各自与总质量联立反演——蛋白 ⇒ s = 34.5/0.23 = **150**；脂肪 ⇒ s = 15.6/0.13 = **120**；碳水 ⇒ s = 45.6/0.38 = **120**。脂肪、碳水互证 s = 120，蛋白读数离群 ⇒ 失准模块是蛋白检测（s=120 时蛋白应为 53.6 g ≠ 60.5 g）。剔除后反演：大豆粉 120 g（燕麦粉 80 g）。

**答案：120**（numeric，单位 g）

### 相邻映射（P3→P4）
- 三种面额硬币 ↔ 两种粉料（成分基数 3→2）；面额权重 ↔ 每克营养含量权重；"观测太少须借整数性补约束" ↔ "观测太多须先甄别真伪"（欠定 ↔ 超定+污染，结构方向反转）；整数/非负筛 ↔ 一致性多数票。
- 共享关系（图式级）：隐藏组成；每条观测 = 组成的加权线性和；反演靠多条观测联立；解的确定性都需要"观测方程之外的推理"补位。
- **照搬探针（错误答案 = 150）**：照搬 P3 的"每条给出的观测都是真约束，抓够方程数就联立"——拿最先给出的蛋白质读数与总质量直接消元得 s = 150 g。错在未检验观测一致性：蛋白模块恰是失准的那台；真值 120（脂肪、碳水两条独立互证）。

### lure（= 照搬上一跳解法的天真版）
题：健身房配餐师装一盒 10 块的能量什锦，混有坚果块（每块 200 kcal）、果干块（每块 90 kcal）、米饼（每块 60 kcal）。营养标签只写了总热量 1000 kcal。三种各几块？【解答】欠定+整数筛：20x+9y+6z=100 与 x+y+z=10 消元得 14x+3y=40 ⇒ x≡2 (mod 3) ⇒ x=2, y=4, z=4，唯一非负整数解 **2;4;4**（400+360+240=1000 ✓）。
- 表面相似：同为食品营养清点、同一批词汇（配料、总量、每份含量）。
- 结构不同：lure 是欠定+丢番图筛（＝上一跳结构的营养换皮），所有观测都可信；目标题观测冗余且含坏数据，照搬 lure 的"约束都真、只愁不够"心智在目标题上会直接吞下失准读数得 150。

verified：python3 分数精确算术：三条成对反演 (150, 120, 120)，多数票 120；s=120 时蛋白理论值 53.6≠60.5 证实蛋白模块失准；照搬答案 150 证伪（与脂肪/碳水两条观测均矛盾）；lure 穷举 11³ 唯一解 (2,4,4)。

## 跳5｜MH-F-5｜L4｜P4（营养检验）→ P5（生态学·稳定同位素混合模型）

**翻转**：除 Schema 外全翻——载体换成稳定同位素食性来源解析（δ¹³C/δ¹⁵N 双示踪）；"观测权重"的语义从每克营养含量变成各食源的同位素端元值；成分回到 3 个而示踪观测只有 2 条，**闭合约束（三源占比之和 = 1）题面不给、须自行补上**才凑满可解系统；题面无"方程/联立/反演"任何提示词，还埋了"传统认为只吃两种猎物"的双源诱导。答案多段式（来源;占比）防蒙对。仅共享"多条加权观测联立反演隐藏组成"图式。

### P5 题面
苔原生态站长期研究一只北极狐的食性。当地可用的食物只有三类，其组织同位素特征稳定：田鼠（δ¹³C = −26‰，δ¹⁵N = 6‰）、海鸟蛋（δ¹³C = −18‰，δ¹⁵N = 14‰）、浆果（δ¹³C = −12‰，δ¹⁵N = 2‰）。传统观点认为这一带的北极狐以田鼠和海鸟蛋为主食，浆果无足轻重。研究者取该狐狸的毛发测得：δ¹³C = −20.8‰，δ¹⁵N = 7.6‰。已知消费者组织的每种同位素比值等于各类食物端元值按摄入比例的加权平均（营养富集效应已在上述读数中校正扣除）。请判断：该狐狸的主要食物来源是哪一类？其摄入占比是百分之多少？（答案格式："来源;占比数字"，如 "浆果;40"）

### P5 解答（多段式；结构需自行识别）
1. **识别结构**（图式再实例化）：狐狸的食性组成 (p田鼠, p蛋, p浆果) 不可直接观测；每种同位素读数都是组成的加权平均——即一条线性观测。两条示踪观测之外，组成本身还隐含**闭合约束 p₁+p₂+p₃ = 1**（题面未给，须自行补上），三条约束恰好锁定三元组成。
2. 列观测方程：p₁+p₂+p₃ = 1；−26p₁ − 18p₂ − 12p₃ = −20.8；6p₁ + 14p₂ + 2p₃ = 7.6。
3. 联立反演：δ¹³C 式 ÷(−2) 减 6×闭合式得 7p₁ + 3p₂ = 4.4；δ¹⁵N 式 ÷2 减闭合式得 2p₁ + 6p₂ = 2.8 ⇒ p₁ + 3p₂ = 1.4；两式相减 6p₁ = 3 ⇒ p₁ = 0.5，p₂ = 0.3，p₃ = 0.2。主要来源 = 田鼠，占比 50%（"浆果无足轻重"的传统观点也被数据推翻：占 20%）。

**答案：田鼠;50**（string，分号分隔两段）

### 相邻映射（P4→P5）
- 大豆粉/燕麦粉 ↔ 田鼠/海鸟蛋/浆果（成分基数 2→3）；每克营养含量权重 ↔ 各食源同位素端元值；化验单读数 ↔ 毛发同位素读数；"总质量 200 g"这条显式观测 ↔ 占比闭合约束（隐式，须自行发现）；"哪条观测是坏的" ↔ "哪个成分被传统观点漏掉了"（怀疑对象从观测转到模型）。
- 共享关系（仅图式级）：隐藏组成不可直接观测；每条可测总量 = 组成的加权线性和；多条观测联立即可反演组成。
- **照搬探针（错误答案 = 海鸟蛋;65）**：照搬 P4 的两组分混合模型——顺着题面"传统观点"只保留田鼠和海鸟蛋两源，用 δ¹³C 单条观测反演：−26p − 18(1−p) = −20.8 ⇒ p田鼠 = 0.35 ⇒ 报"海鸟蛋;65"。错在成分基数不能从上一跳继承：换用 δ¹⁵N 同样反演会得 p田鼠 = 0.8，两条观测在双源模型下互相打架，正说明第三个来源不可省略；真值"田鼠;50"。

### lure（同域·异图式，SPEC L4 规定）
题：同一生态站用 δ¹⁵N 估营养级：浮游/初级生产者基线 δ¹⁵N = 0.8‰，每上升一个营养级组织 δ¹⁵N 富集 3.4‰。某北极狐毛发 δ¹⁵N = 7.6‰，问其营养级是多少？【解答】营养级 = 1 + (7.6 − 0.8)/3.4 = **3.0**。
- 表面相似：同一生态站、同一动物、同一批词汇（δ¹⁵N、‰、毛发、食物网）。
- 结构不同：阶梯富集标定是"单观测÷固定步长"的一维刻度换算，无组成、无联立；照搬其"作差除步长"算子到食性解析题上得不到任何占比。

verified：python3 numpy 解 3×3 系统 = (0.5, 0.3, 0.2)，分数精确算术复核两条观测严格吻合；照搬双源 δ¹³C 反演 p田鼠 = 0.35（⇒ 海鸟蛋;65）与 δ¹⁵N 反演 p田鼠 = 0.8 互相矛盾，双双证伪；lure 1+(7.6−0.8)/3.4 = 3.0。
