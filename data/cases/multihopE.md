# 多跳长链 E-multihop-01（线程 E-信噪判别）

> 与 chainE 的区别：chainE 是"源固定、只有目标动"；本链是**连环迁移**——同一抽象图式在 P0→P1→P2→P3→P4→P5 六个节点间接力，**每跳的源题是上一跳的题**，学科每跳都换。测的是迁移的传递性：在 Pi→Pi+1 学到的映射能否接力到下一跳。学科域与 chainE 零重叠（chainE：深空导频、水声通信、临床检验、伽马谱仪、生态种群；本链：掷骰→篮球裁判→选举审计→焊缝疲劳→地下水监测→连锁餐饮运营）。
>
> 固定图式 Schema："真信号淹没在随机涨落里，可靠判别要求信号的期望偏移超出涨落幅度一个与置信要求挂钩的裕量；重复/累积观测使期望偏移线性拉开、涨落只按观测量的平方根增长，从而压低相对涨落。"解法三步式：**估涨落 → 定裕量 → 反解观测量**。
>
> **去脚手架约定（吸取 harness/REPORT.md 第三节教训）**：任何一跳的题面都只给原始事实（基础概率、独立性、观测量、误判率要求）与所需的正态分位数**数值本身**（如"1% 上尾对应 2.33，可直接取用"）——"涨落幅度按观测量平方根增长""方差相加""族误报按并联数换算"等全部规律**一律不进题面**，必须由被测模型自己从独立计数的结构中推出。判定规则统一为两条事实性要求：(i) 误判率 ≤ 指定值；(ii) 判定线不高于真异常时的期望值（保证真异常平均而言被判出）——这是任务规格，不是涨落模型。
>
> 结构距离逐跳升级：跳1 仅翻 Surface（同为"频数偏离已知基线"判别，严格同构）；跳2 跨科仍同构；跳3 涨落来源改变（基线不再精确已知、须由同规模试验估计——两组涨落方差相加，照搬单组式会错）；跳4 多重比较（10 路并联共享误报预算，裕量档位须按并联数收紧，照搬单检验裕量会错）；跳5 只剩图式（L4：载体全新、题面零统计词汇，须自行识别"运气 vs 真问题"的判别结构、选涨落模型、还原 25 选 1 的选择效应，多段式答案）。
>
> 全部答案（含每个照搬错误答案、lure 自身答案）已用 python3 精确验证（闭式反解 + 整数边界断言 + 精确二项尾概率复核，脚本逻辑记录于各跳 verified）。

## P0（锚点）｜概率·掷骰鉴定

### 题面
赌场监察部收缴了一枚可疑骰子。这类灌铅骰子的特点是"六点"朝上的概率被抬高到 1/4；而公平骰子掷出六点的概率为 1/6，各次投掷相互独立。监察部的鉴定方案：把骰子掷 n 次，数出六点朝上的次数，若超过预先划定的判定线，即判定为灌铅骰。方案须同时满足：(i) 若骰子其实公平，被误判为灌铅的概率不超过 1%（如需，1% 上尾概率对应的正态分位数 2.33 可直接取用）；(ii) 判定线不得高于灌铅骰六点次数的期望值（保证真灌铅骰平均而言会被判出）。问 n 至少取多少？

### 解答（显式暴露三步图式）
1. **估涨落**：公平骰下六点次数 X 是 n 次独立成/败试验的计数 ⇒ X ~ 二项(n, 1/6)：期望 n/6，方差 n·(1/6)(5/6) = 5n/36，典型涨落幅度 σ = √(5n/36) ≈ 0.3727√n。关键：灌铅与公平的期望差距 (1/4−1/6)n = n/12 随 n **线性**拉开，涨落只按 **√n** 增长——多掷即可压低相对涨落，这一规律由二项方差推出（题面未给）。
2. **定裕量**：误判率 ≤1% ⇒ 判定线 T = n/6 + 2.33σ（期望计数 ≥18，正态近似成立）。
3. **反解观测量**：条件(ii) 要求 n/4 ≥ T ⟺ n/12 ≥ 2.33×0.3727×√n ⟺ √n ≥ 10.420 ⟺ n ≥ 108.6 ⇒ **n = 109**。（复核：n=109 时 T=27.23 ≤ 灌铅期望 27.25 ✓；n=108 时 T=27.02 > 27.00 ✗。）

**答案：109**（numeric。python3：n≥108.578，边界 108 失败/109 成立断言通过；精确二项复核 P(X>27|公平)=1.10%、灌铅检出 47%。）

## 跳1｜MH-E-1｜L1｜P0（掷骰鉴定）→ P1（体育·裁判判罚复核）

**翻转**：仅 Surface（骰子→裁判、掷骰→边界判罚、灌铅概率 1/4→偏袒概率 60%、基线 1/6→1/2）。Model（单组二项计数 vs 已知基线）、Method（估涨落→定裕量→反解 n）、Schema 全同——严格同构。

### P1 题面
某职业篮球联赛纪律委员会收到对裁判 K 偏袒主队的举报。联盟的复核流程：从其执裁比赛的录像中调取"争抢球权、判给两队皆可"的边界判罚片段——独立回放中心的盲评已确认，公正裁判把这类判罚判给主队与客队的机会各为一半，且各次判罚相互独立；而据既往查实的案例，受主队方面影响的裁判会把这类判罚的 60% 判给主队。委员会将复核 n 次这类判罚，数出判给主队的次数，超过判定线即启动正式调查。要求：(i) 对公正裁判误启动调查的概率不超过 1%（1% 上尾对应的正态分位数 2.33 可直接取用）；(ii) 判定线不高于偏袒裁判判给主队次数的期望值。问至少复核多少次判罚？

### P1 解答
1. 估涨落：公正裁判下"判给主队"次数 ~ 二项(n, 1/2)：期望 n/2，方差 n/4，σ = 0.5√n；期望差距 0.1n 线性拉开、涨落按 √n 增长。
2. 定裕量：T = n/2 + 2.33×0.5√n。
3. 反解：0.6n ≥ T ⟺ √n ≥ 2.33×0.5/0.1 = 11.65 ⟺ n ≥ 135.73 ⇒ **n = 136**。

**答案：136**（numeric）

### 相邻映射（P0→P1）
- 骰子 ↔ 裁判 K；掷骰一次 ↔ 复核一次边界判罚；六点朝上 ↔ 判给主队；公平基线 1/6 ↔ 公正基线 1/2；灌铅抬到 1/4 ↔ 偏袒抬到 60%；判定灌铅 ↔ 启动调查。
- 共享关系（严格同构）：n 次独立成败试验计数；基线概率精确已知；异常使成功率上移固定量；判定线 = 基线期望 + 与 1% 挂钩的裕量；反解最小 n。
- 照搬探针：无（严格同构，上一跳三步法照搬即对——本跳作 TRR 高端锚点）。lure：null（SPEC L1 允许）。

verified：python3 闭式 n≥135.7225、边界 135 失败/136 成立断言通过；精确二项复核误判 1.01%、偏袒检出 51%。

## 跳2｜MH-E-2｜L2｜P1（体育裁判）→ P2（政治学·选举风险审计）

**翻转**：Surface + Domain（体育纪律 → 选举治理；行为频数 → 抽样计票）；Model/Method 严格同构——剥掉外衣仍是"单组独立计数 vs 精确已知基线 46%，异常上移 5 个百分点，反解最小观测量"。Schema 同。

### P2 题面
某选区全部选票由光学计票机计数，机器公布候选人 A 的得票率为 46.0%。选举观察组织收到线报：计票固件可能被植入了移票程序，若属实，A 的真实得票率应为 51.0%（5 个百分点被移记给对手）。当地选举法允许发起"风险审计"：从全部纸质选票中随机抽取 n 张人工认读（纸质票是事实标准；选票总数极大，可视为每张抽取相互独立、抽中 A 票的概率恒定），数出其中 A 的票数，超过判定线即强制全量人工重计。要求：(i) 机器计票诚实时，误触发全量重计的概率不超过 1%（1% 上尾对应的正态分位数 2.33 可直接取用）；(ii) 判定线不高于移票属实时抽样中 A 票数的期望值。问至少抽取多少张选票？

### P2 解答
1. 估涨落：机器诚实时抽样中 A 票数 ~ 二项(n, 0.46)：期望 0.46n，方差 n×0.46×0.54 = 0.2484n，σ = 0.4984√n。
2. 定裕量：T = 0.46n + 2.33×0.4984√n。
3. 反解：0.51n ≥ T ⟺ √n ≥ 2.33×0.4984/0.05 = 23.23 ⟺ n ≥ 539.42 ⇒ **n = 540**。

**答案：540**（numeric）

### 相邻映射（P1→P2）
- 裁判 K ↔ 计票机；一次边界判罚 ↔ 抽读一张纸质选票；判给主队 ↔ 认读为 A 票；公正基线 50% ↔ 诚实基线 46%；偏袒 60% ↔ 移票后真实 51%；启动调查 ↔ 强制全量重计。
- 共享关系（严格同构）：独立成败计数；基线精确已知；异常 = 概率固定上移；判定线 = 基线期望 + 1% 裕量；期望差线性、涨落按 √n ⇒ 反解 n。
- 照搬探针：无（同构，方法照搬即对；注意基线概率首次偏离对称值，方差因子须实算 0.46×0.54 而非套 1/4）。

### lure（同学科·异结构，SPEC L2 规定）
题：某市长选举开票至 96%，候选人 A 落后 B 共 2,406 票，尚有 5 个投票点未计，每个投票点至多 900 张票。问 A 是否仍有翻盘可能？【解答】最坏情形界：剩余至多 5×900 = 4,500 票即便全部投 A，净增 4,500 > 2,406 ⇒ 有翻盘可能。
- 表面相似：同为选举计票争议、同问"公布结果是否可能被推翻"。
- 结构不同：lure 是确定性最坏情形的代数比较（剩余票数 vs 票差），无抽样、无涨落；目标题的判定对象是随机抽样计数围绕期望的涨落，判定线由涨落幅度与误判率共同决定。把"差多少票补多少票"的确定性思路搬到抽样审计，会完全丢掉裕量结构。

verified：python3 闭式 n≥539.4155、边界 539 失败/540 成立断言通过；精确二项复核误触发 0.97%、移票检出 50%；lure 4500>2406 复核。

## 跳3｜MH-E-3｜L3｜P2（选举审计）→ P3（材料工程·焊缝疲劳验收）

**翻转**：Surface + Domain + **Model/Method（涨落来源改变）**——基线不再是精确已知常数：老产线失效率同样须由 n 件试验估计，判别量从"计数 vs 已知期望"变为"两个都在涨落的比例之差"，**差值的方差 = 两组方差之和**。照搬上一跳的单组公式（只算一组涨落）会把所需样本量低估一半。Schema 同（仍是"期望偏移须超出涨落一个 1% 裕量"）。

### P3 题面
某桥梁钢构厂把关键焊缝的生产由老产线迁往新产线，质检部门怀疑新产线焊缝在标准疲劳载荷谱试验下的失效率劣化到了老产线的约两倍。可用的背景信息：行业经验表明这类焊缝在该载荷谱下的失效率大致在 10% 一带（可用于规划估算）；但老产线从未做过大规模精确测定，档案中不存在可直接引用的精确失效率。验收规程因此规定：从老产线留存件与新产线产出件中各随机抽取 n 件，同批完成疲劳试验（各件失效与否相互独立），分别数出两组失效件数并折算失效比例；若新产线失效比例超出老产线失效比例达到一个预先划定的判定裕量，即判"劣化"、新产线停线整改。要求：(i) 两产线实际同质（失效率同处 10% 水平）时，误判停线的概率不超过 1%（1% 上尾对应的正态分位数 2.33 可直接取用）；(ii) 判定裕量不大于新产线真劣化到 20% 时两组失效比例之差的期望值（保证真劣化平均而言会被判出）。问每组至少抽多少件？

### P3 解答（涨落来源需重造）
1. 估涨落：同质时两组失效比例**各自**围绕 10% 涨落（单组比例方差 0.1×0.9/n = 0.09/n），且相互独立 ⇒ 判别量"新−老比例差"期望为 0，方差 = **两组方差之和** = 0.18/n，σ_diff = √(0.18/n)。（关键结构变化：上一跳的基线是精确常数、零涨落；本跳基线自身由同规模试验估得，其涨落同量级进入差值。）
2. 定裕量：误停线 ≤1% ⇒ 判定裕量 M = 2.33×√(0.18/n)。
3. 反解：条件(ii) 0.20−0.10 = 0.10 ≥ M ⟺ n ≥ 2.33²×0.18/0.01 = 97.72 ⇒ **每组 98 件**。

**答案：98**（numeric，每组件数）

### 相邻映射（P2→P3）
- 计票机公布值 46% ↔ 老产线失效率（**由"精确已知"降级为"须同批试验估计"**——这是本跳的结构翻转点）；抽读选票 ↔ 抽件做疲劳试验；A 票计数 ↔ 失效件数；移票抬升 5pp ↔ 劣化抬升 10pp；强制重计 ↔ 停线整改。
- 共享关系（图式级）：独立成败计数的涨落决定可判别性；判定线/裕量与 1% 误判率挂钩；期望偏移线性、涨落按 √n ⇒ 反解最小观测量。
- **照搬探针（错误答案 = 49）**：照搬 P2 的单组式——把行业经验值 10% 当精确基线，只考虑新产线一组的涨落（方差 0.09/n），得 n ≥ 2.33²×0.09/0.01 = 48.86 ⇒ 49。错在老产线比例同样由 49 件估得，其涨落同量级进入差值：真实方差 0.18/n 是照搬值的 2 倍，裕量被低估 √2 倍——n=49 时真实误停线率 ≈ 5%，超标 5 倍。真值 98。

### lure（= 照搬上一跳解法的天真版）
题：另一类标准角焊缝的失效率由国家标准大样本数据**精确**给定为 10%。对某新产线抽 n 件做同谱疲劳试验，失效比例超出 10% 达到判定裕量即判劣化；误判 ≤1%（2.33 可用），裕量不大于真劣化到 20% 时的期望超出量。求最少件数。【解答】单组：n ≥ 2.33²×0.09/0.01 = 48.86 ⇒ 49 件。
- 表面相似：同为焊缝疲劳验收、同样的 10%/20% 与 1% 要求、同问最少件数。
- 结构不同：lure 的基线由国标精确给定、零涨落，单组方差 0.09/n 即全部涨落；目标题基线须由同规模试验估计，两组方差相加为 0.18/n。照搬 lure 的 49 到目标题即得错误答案，真值 98。

verified：python3 闭式两组式 n≥97.7202、边界 97 失败/98 成立断言通过；照搬单组式 48.8601→49 复核；n=49+单组裕量下真实误停线率 4.97%（正态）证伪照搬解。

## 跳4｜MH-E-4｜L3｜P3（焊缝验收）→ P4（环境工程·地下水监测网）

**翻转**：Surface + Domain + **裕量结构再变（多重比较）**——基线回到精确已知（方法学假阳性率 30%），但判定同时施加于 **10 口井**：误报预算 1% 是全网共享的，"至少误报一口"≈ 单井误报率 × 10，单井档位须压到 0.1%、裕量从 2.33σ 收紧到 3.09σ。照搬上一跳（或任何单检验）的 1% 裕量会错。Schema 同。

### P4 题面
某工业园区周边含水层布设了 10 口地下水监测井，用同一种快速筛查法检测特征污染物。方法学背景：未受污染的井中，天然腐殖酸会与试剂交叉反应，使单次水样呈"阳性"的概率长期稳定在 30%（各次采样化验相互独立）；若某井所在含水层已被污染物侵入，单次阳性概率会升到 45%。环保部门计划对每口井全年各采样化验 n 次，年末分别数出各井的阳性次数，超过判定线的井上报省厅并启动溯源钻探。要求：(i) 10 口井全部未受污染时，全年"至少误报一口井"的概率不超过 1%；(ii) 判定线不高于受污染井阳性次数的期望值。备查正态上尾分位数（可直接取用）：1%→2.33，0.5%→2.576，0.1%→3.09，0.05%→3.29，0.04%→3.35，0.01%→3.72。问每口井全年至少采样化验多少次？

### P4 解答（裕量档位需重造）
1. 估涨落：未污染井的年阳性次数 ~ 二项(n, 0.30)：期望 0.3n，方差 0.21n，σ = 0.4583√n。
2. 定裕量：**误报要求是全网 1%，不是单井 1%**——10 口井独立受检，"至少一口误报"的概率 ≈ 10 × 单井误报率（并联界），故单井误报率须压到 1%/10 = 0.1%，取分位数 3.09：判定线 T = 0.3n + 3.09×0.4583√n。
3. 反解：0.45n ≥ T ⟺ √n ≥ 3.09×0.4583/0.15 = 9.440 ⟺ n ≥ 89.12 ⇒ **n = 90**。

**答案：90**（numeric，每井年采样次数）

### 相邻映射（P3→P4）
- 两条产线的对比 ↔ 10 口井各自 vs 已知方法学基线（基线回到精确已知，两组方差相加的结构退场；新结构 = 多路并联共享误报预算）；抽件试验 ↔ 采样化验；失效 ↔ 阳性；劣化 10%→20% ↔ 污染 30%→45%；停线整改 ↔ 上报溯源。
- 共享关系（图式级）：独立计数涨落 vs 期望偏移；裕量与误判率挂钩；期望差线性、涨落按 √n ⇒ 反解最小 n。
- **照搬探针（错误答案 = 51）**：沿用上一跳的单检验 1% 裕量 2.33 ⇒ √n ≥ 2.33×0.4583/0.15 ⇒ n ≥ 50.67 ⇒ 51。错在 1% 是 10 口井共享的族预算：每井各留 1% 时，全网至少一井误报概率 ≈ 1−0.99¹⁰ ≈ 9.6%，超标近 10 倍；正确做法把单井档位摊薄到 0.1%（3.09），真值 90。

### lure（= 照搬上一跳裕量结构的天真版）
题：某化工厂厂界内只有**一口**自备监测井，用同一筛查法（未污染单次阳性率 30%，污染后 45%，各次独立）。全年采样 n 次，阳性次数超过判定线即停产自查；误停产概率 ≤1%（2.33 可用），判定线不高于污染时的期望阳性次数。求全年最少采样次数。【解答】单井单检验：√n ≥ 2.33×0.4583/0.15 ⇒ n ≥ 50.67 ⇒ 51 次。
- 表面相似：同一筛查法、同样的 30%/45% 与 1% 字样、同问最少采样次数。
- 结构不同：lure 只有一路检验，1% 预算全花在一口井上；目标题 10 路并联共享 1%，单井档位须收紧到 0.1%。照搬 lure 的 51 即得错误答案，真值 90。

verified：python3 闭式 n≥89.1156、边界 89 失败/90 成立断言通过；照搬 2.33 得 50.6697→51 复核，其全网误报率 9.47% 证伪；n=90 判定线 T=40.43（期望检出 27，正态近似有效区），精确二项复核单井误报 0.132%、全网 1.31%、污染井检出 50%。

## 跳5｜MH-E-5｜L4｜P4（地下水监测）→ P5（连锁餐饮运营·门店问责）

**翻转**：除 Schema 外全翻——题面**零统计词汇**（无"概率抬升的备择方"、无"判定线"、无"误判率"术语，只有一位总监、一张差评排行榜和一条合规红线）；判别结构（这是"运气 vs 真问题"）、涨落模型（1600 单独立小概率计数 ⇒ 二项/泊松，σ=5.6）、多重比较（"排名找最差"= 25 家店取最大值的选择效应）全部须自行识别与重建；问题形态从"反解 n"变为"判定 + 反解最低计数"，答案多段式防蒙对。仅共享"信号须超出涨落一个与置信挂钩的裕量"图式。

### P5 题面
某连锁咖啡品牌旗下有 25 家门店，上一季度每家店都恰好完成了 1600 份外送订单。品牌多年的运营数据：任何一份外送订单收到差评的机会稳定在 2%，一单是否差评与其他订单互不影响、也与哪家门店无关——既往复盘显示差评几乎全部来自配送途中的随机状况（堵车、天气、餐损），而非门店自身。本季度结束，运营总监把 25 家店的差评单数从高到低排出，最高的一家有 49 单，比全品牌平均水平高出一半还多；总监拟据此认定该店"确实存在经营问题"，对店长通报批评并扣发季度奖金。品牌合规部只有一条硬性规定：所有门店都正常经营时，这套"排名找最差、达线即问责"的流程冤枉到任何一家正常门店的总机会不得超过 1%。备查（如用到）：正态上尾概率 1%、0.1%、0.04%、0.01% 对应的分位数分别为 2.33、3.09、3.35、3.72，按正态处理即可。问：(a) 这 49 单差评能否作为合规的问责依据？(b) 在这套流程下，榜首门店的差评单数至少要达到多少单，问责才合规？答案按"能;单数"或"不能;单数"格式作答。

### P5 解答（结构与涨落模型均需自建）
1. **识别结构 + 估涨落**：差评只由订单级随机状况驱动 ⇒ 每店季度差评数是 1600 次独立小概率事件的计数，围绕期望 1600×2% = 32 单自然起伏——"49 单是否说明有问题"就是"49 是否超出纯运气涨落可解释的范围"。计数涨落：二项方差 1600×0.02×0.98 = 31.36 ⇒ σ = 5.6 单（按泊松 σ=√32≈5.66 同样成立，下同）。
2. **定裕量（还原选择效应）**：问责流程盯的是 25 家店的**榜首**——所有店都正常时，"至少一家被冤枉" ≈ 单店被冤枉概率 × 25 ⇒ 单店档位须压到 1%/25 = 0.04%，对应分位数 3.35 ⇒ 合规问责线 = 32 + 3.35×5.6 = 50.76 单。
3. **判定与反解**：49 < 50.76 ⇒ (a) **不能**——49 单落在 25 家正常门店取最大值的正常运气范围内；(b) 榜首至少 **51** 单（50.76 之上的最小整数；泊松口径 32+3.35×5.66=50.95，同样取 51）。

**答案：不能;51**（string，分号分隔两段）

### 相邻映射（P4→P5）
- 10 口监测井 ↔ 25 家门店（并联结构隐藏进"排名找最差"的叙事）；采样化验一次 ↔ 一份外送订单；假阳性率 30% ↔ 差评率 2%；污染井 ↔ "真有问题"的门店（题面不再给其参数——不需要：问的是判定而非样本量）；上报溯源 ↔ 通报批评扣奖金；全网误报 ≤1% ↔ 冤枉任何正常门店的总机会 ≤1%。
- 共享关系（仅图式级）：独立计数围绕期望的涨落；真信号须超出涨落一个与置信要求挂钩的裕量才可靠；多路取最大时裕量档位按路数摊薄。
- **照搬探针（错误答案 = 能;46）**：沿用单店 1% 裕量 2.33、无视"专挑 25 家里最大的"这一选择效应 ⇒ 问责线 = 32 + 2.33×5.6 = 45.05 ⇒ 46 单；49 ≥ 46 ⇒ 判"能"——**决策方向整个反转**。该规则下 25 家全正常时至少一家被冤枉的概率（精确二项）≈ 24%，违反合规红线 24 倍。真值"不能;51"。

### lure（同域·异图式，SPEC L4 规定）
题：外卖平台规定：门店季度差评率超过 3% 即下架。某门店本季已完成 1,200 单、收到差评 30 单，季末前还要完成 400 单。问剩余 400 单中差评至多多少单，才能保住不被下架？【解答】确定性配额：全季 1,600 单的限额为 3%×1600 = 48 单，已用 30 单 ⇒ 剩余至多 48−30 = **18** 单。
- 表面相似：同为门店外送差评单数、同为 1600 单季度体量、同问"多少单是红线"。
- 结构不同：lure 是确定性配额分解（固定限额一减到底），没有"随机涨落 vs 真实问题"的判别结构，更没有多店取最大的选择效应；把"拿固定红线直接比大小"的思路搬到目标题，恰好复现总监"49 比平均 32 高出一半 ⇒ 有问题"的错误——固定数值比较区分不了运气与信号。

verified：python3——正确线 T=50.760（49 不达线、最小达线整数 51）、照搬线 T=45.048（49 达线、最小整数 46）断言通过；二项 σ=5.6 与泊松 σ=5.657 两种口径阈值同为 51/46（答案对涨落模型选择稳健）；精确二项参考：单店 P(X≥51)=0.105%、25 店族 2.6%（正态口径为题面明示的判分标准），照搬阈值 46 的族误罚率 23.9% 证伪；lure 48−30=18 复核。
