# 变换算子法（mutation）构造案例

> 构造方法研究：定义一组作用在题目四元组（Surface / Domain / Model / Method / Schema，SPEC §1）上的显式变换算子，从已验证的种子题出发逐算子推导新 case，保留完整推导链。
>
> 算子清单：
> - **T-reskin**（换 Surface/Domain）：换叙事域词汇，Model 不动 → 产出 L1/L2；
> - **T-couple**（改 Model）：把独立量改相依 / 加隐藏约束 / 连续改离散 → 把 L2 推向 L3；
> - **T-noise**（改噪声/反馈结构）：固定参数改随机、加观测误差 → 推向 L3/L4；
> - **T-invert**（反转问法）：正问改逆问（求参数→求时刻/求源）。
>
> 本文件 3 题：2 道由 L2 种子推 L3（各施 2 个算子），1 道由新推出的 L3 继续推 L4（链式变异）。机器可读版见 methodMut.jsonl（`"method": "mutation"`，`"derivation"` 字段记录推导链）。

## L3-F-MU01 ｜ F-逆问题 ｜ 金融 → 环境工程 ｜ 恒定输入驱动下的源事件回溯

### 【种子题引用】

种子：**L2-F-05**（金融连续复利两次查账回推开户日 ↔ 药理两次采血回推给药时刻）。
种子 Model：单指数过程 A·e^{±kt}；种子 Method：两观测**原始值比值**消元定参 → 对数回溯源事件时刻。
本 case 的 source 直接沿用 L2-F-05 的源题（金融开户日回推）及其完整解答。

### 【算子推导链】

`L2-F-05 → T-reskin → T-couple ⇒ L3-F-MU01`

| 算子 | 翻转的四元组成分 | 具体操作 |
| --- | --- | --- |
| T-reskin | Surface + Domain | 账户/血药叙事 → 河道污染物存量叙事（金融/药理 → 环境工程），数值全部重设 |
| T-couple | **Model**（连续改离散 + 独立量改相依） | 连续指数衰减 → 逐日离散结算；纯衰减 → 衰减与**恒定外源输入耦合**（x_n = ρ·x_{n−1} + c），系统出现非零固定点 x* = c/(1−ρ)，"原始值比值 = 几何比"这一核心恒等式失效，只在**对固定点的偏差**上成立 |

难度归级论证（L3 判据）：核心关系保持（偏差量 x_n − x* 仍是几何衰减、仍是"两观测定参 → 对数回溯源事件"的逆问题图式，Schema 同、线程 F 同）；但不存在完整同构——照搬种子的原始值比值法会得到系统性错误的速率与回溯时刻（错误答案 ≈ 8.8 天，真值 6 天）。Method 需适配：**先扣除固定点（等价地：对相邻观测取差分）再取比值**，且需要第三个观测点才能恰定。

### 【题面 + 解答】

**source（= L2-F-05 源题，金融）**：某账户开户时一次性存入 5000 元，此后按未知的连续复利年利率 r 增长，无其他存取。2019-01-01 查得余额 7200 元；2023-01-01 查得余额 10368 元。问开户日在 2019-01-01 之前多少年？（保留 1 位小数）
解答：B(t)=5000·e^{rt}；比值定参 10368/7200=1.44=e^{4r} ⇒ r=ln1.44/4≈0.09116；回溯 7200/5000=1.44=e^{r·t₁} ⇒ t₁=4.0 年。答案 **4.0**。

**target（环境工程/河道监测）**：某河段监测点按日终结算污染物存量：每天存量先按未知恒定的日保留率 ρ（0<ρ<1）自然降解，随后上游化工园区按排污许可**恒定排入 40 kg**。第 0 天日终发生一次事故性泄漏，使当日日终存量跳升至 1000 kg。环保督察后来才介入，从第 n₁ 天（n₁ 未知）日终起采样三次：第 n₁ 天、第 n₁+2 天、第 n₁+4 天的日终存量读数分别为 409.7、334.2、285.9 kg。问 n₁ 是多少天？（答一个整数）

**解答（适配后的算子序列）**：
1. 建模：x_n = ρ·x_{n−1} + 40，固定点 x* = 40/(1−ρ)，偏差 y_n = x_n − x* 满足 y_n = y_0·ρⁿ（纯几何）；
2. **差分消固定点**（Method 适配步）：相邻观测差 v₂−v₁ 与 v₃−v₂ 都正比于 ρ^{n₁}，比值 (285.9−334.2)/(334.2−409.7) = 0.63973 = ρ² ⇒ ρ ≈ 0.7998；
3. 求固定点：x* = 40/(1−ρ) ≈ 199.8；
4. 对数回溯（对偏差量）：n₁ = ln((409.7−x*)/(1000−x*)) / ln ρ = ln(0.26228)/ln(0.79983) ≈ 5.99 ⇒ **n₁ = 6**。

答案：**6**（numeric，tolerance 0）

**照搬为什么错（负迁移探针）**：直接套种子的原始值比值法——√(334.2/409.7)=0.9032 当作"ρ"，再 ln(409.7/1000)/ln(0.9032) ≈ **8.76 ⇒ 报约 8.8 或 9 天**（错误）。错因：恒定输入抬高了尾部读数，原始值比值不再等于几何比，既高估保留率又高估回溯时长；必须先扣除 x* = 200 的稳态本底。

**lure（源解法的天真照搬版，L3 约定）**：同一河段的**无排放上游支流**（c = 0）：第 0 天日终泄漏使存量为 1000 kg，第 n₁ 与 n₁+2 天日终读数 512.0、327.7 kg，问 n₁。【解答】纯几何衰减，原始值比值直接可用：ρ=√(327.7/512.0)=0.800，n₁=ln(0.512)/ln(0.8)=**3 天**。
- 表面相似：同一条河、同一套"泄漏日回溯"叙事、同样的两/三次日终采样数据形态。
- 结构不同：无外源输入 ⇒ 固定点为 0，原始值即偏差量，比值法恰好成立；把这套算子搬回 target（c=40）得 8.8 天而非 6 天。

### 【验证】

python3（scratchpad/verify_mu.py）：正向模拟递推 ρ=0.8, c=40, x₀=1000 得 x₆=409.7152, x₈=334.2177, x₁₀=285.8993（与题面舍入值一致）；再仅从题面舍入观测反演：ρ̂=0.799834, n̂₁=5.992 → 6 ✓；照搬法 n₁=8.762（≈8.8）✓ 与真值可区分；lure 无排放版比值法 n₁=3.000 ✓。断言全部通过。

冷启动自评：需要识别仿射递推的固定点结构并想到差分/去稳态，估计 target-only 正确率 30–55%，落在 20–60% 净空区间。

## L3-E-MU02 ｜ E-信噪判别 ｜ 医学诊断 → 地球物理 ｜ 共模噪声破坏条件独立的双传感器融合

### 【种子题引用】

种子：**L2-E-04**（医学双重复检 ↔ 网络安全双检测器：极低先验下双条件独立检出的贝叶斯后验）。
种子 Model：二元假设 + 两次条件独立观测；种子 Method：似然平方 p·s²/(p·s²+(1−p)·f²)。
本 case 的 source 直接沿用 L2-E-04 的源题（罕见代谢病两次独立复检）及其完整解答。

### 【算子推导链】

`L2-E-04 → T-reskin → T-couple ⇒ L3-E-MU02`

| 算子 | 翻转的四元组成分 | 具体操作 |
| --- | --- | --- |
| T-reskin | Surface + Domain | 临床筛查/安全运营叙事 → 地震前震预警叙事（医学 → 地球物理），率值全部重设 |
| T-couple | **Model**（独立量改相依） | "给定类别时两次观测条件独立"这一独立性假设被**共因噪声源**破坏：无事件时两阵列共享地脉动暴发（共模干扰），误报相依；似然平方公式对噪声侧失效，须按分层共因结构算联合误报概率 |

难度归级论证（L3 判据）：核心关系保持（二元假设、双观测贝叶斯融合、"信号项须压过假阳性噪声底"的 E-线程图式，信号侧似然仍独立平方）；但噪声侧联合似然 P(双告警|无事件) = q·b² + (1−q)·e² ≠ (边际误报率)²——照搬种子的"边际平方"会把后验从 34.8% 高估到 78.0%。Method 适配步：先按共因分层展开联合概率，再进贝叶斯。

### 【题面 + 解答】

**source（= L2-E-04 源题，医学诊断）**：某罕见代谢病患病率 1%。筛查试验敏感度 85%、特异度 95%。对同一受检者做两次条件独立的该试验，两次均为阳性。求此人实际患病的概率（百分数，保留 1 位小数）。
解答：条件独立 ⇒ 似然平方：0.01×0.85² / (0.01×0.85² + 0.99×0.05²) = 0.007225/0.0097 = **74.5%**。

**target（地球物理/地震预警）**：某断裂带的分钟级监测窗口中，真实"前震信号"基率 1%。两个台阵 A、B 同时监测：**有前震时**，各台阵检出率均 85%，且给定前震发生，二者检出相互独立。**无前震时**，误报有两类来源：(i) 区域性地脉动暴发，每窗口发生概率 2%，一旦发生，两台阵各以 80% 概率被触发（给定暴发，二者独立）；(ii) 无暴发时，各台阵仅因本机电子噪声独立误报，概率各 3%。（由此单台阵综合误报率 = 2%×80% + 98%×3% = 4.54%。）某窗口 A、B 同时告警，求该窗口确有前震的概率（百分数，保留 1 位小数）。

**解答（适配后的算子序列）**：
1. 信号侧（独立仍成立）：P(双告警|前震) = 0.85² = 0.7225；
2. **噪声侧按共因分层展开**（Method 适配步，不能平方边际）：P(双告警|无前震) = 0.02×0.8² + 0.98×0.03² = 0.0128 + 0.000882 = 0.013682；
3. 贝叶斯归一化：后验 = 0.01×0.7225 / (0.01×0.7225 + 0.99×0.013682) = 0.007225/0.020770 = **34.8%**。

答案：**34.8**（numeric，tolerance 0.2）

**照搬为什么错（负迁移探针）**：套种子公式，把题面给出的单台阵综合误报率 4.54% 平方——0.007225/(0.007225+0.99×0.0454²) = **78.0%**（错误，高估 43 个百分点）。错因：共模暴发让两台阵误报强相关，联合误报概率 0.013682 是"边际平方" 0.00206 的 **6.6 倍**——相依噪声底被独立性假设整整低估了一个数量级级别，"第二个告警"提供的确证信息远小于独立情形。

**lure（源解法的天真照搬版，L3 约定）**：两个台阵部署在**地质上完全隔离**的两个台址（相距 300 km、无共享噪声源），各自仅因本机电子噪声独立误报 4.54%，检出率与基率同上；双告警求后验。【解答】此时条件独立真成立，似然平方合法：0.007225/(0.007225+0.99×0.0454²) = **78.0%**。
- 表面相似：同一套台阵/前震/双告警词汇，同样的率值，同问"双告警后是前震的概率"。
- 结构不同：lure 无共因噪声，独立平方恰好正确；把这套算子搬回 target（共址共模）得 78.0% 而非 34.8%——lure 的正确答案恰好就是 target 的照搬错误答案，负迁移信号最大化。

### 【验证】

python3（scratchpad/verify_mu.py）：精确计算 P(双|无事件)=0.013682，正确后验 0.347854 → 34.8 ✓；照搬边际平方后验 0.779770 → 78.0 ✓；lure 独立版后验 78.0 ✓。断言全部通过。

冷启动自评：需要拒绝"边际误报率平方"的顺手路径、按共因分层建模联合似然，估计 target-only 正确率 25–50%。

## L4-F-MU03 ｜ F-逆问题 ｜ 环境工程 → 基因组流行病学 ｜ 泊松观测噪声下的源事件 MAP 溯源

### 【种子题引用】

种子：**L3-F-MU01**（本文件第 1 题，链式变异：L2-F-05 → L3-F-MU01 → 本题）。
种子 Model：确定性仿射递推 + 精确读数；种子 Method：差分定参 → 固定点扣除 → 对数回溯出**唯一确定**的源事件时刻。
本 case 的 source = L3-F-MU01 的 target（河道泄漏日回溯）及其完整解答。

### 【算子推导链】

`L2-F-05 → (T-reskin + T-couple) → L3-F-MU01 → T-noise → T-reskin ⇒ L4-F-MU03`

| 算子 | 翻转的四元组成分 | 具体操作 |
| --- | --- | --- |
| T-noise | **Model + Method**（固定参数演化改随机过程、精确观测改计数噪声） | 确定性递推 x_n = ρx_{n−1}+c → **泊松计数过程**（观测量本身是随机变量，同一源时刻可产生不同计数）；"反解方程得唯一时刻" → **不复存在**，只能在离散候选假设上做似然×先验的 MAP 推断并给出后验置信度 |
| T-reskin | Surface + Domain | 河道污染物叙事 → 医院感染分子溯源叙事（环境工程 → 基因组流行病学） |

难度归级论证（L4 判据）：Model 异（确定性线性系统 → 泊松随机计数）、Method 异（差分定参+对数回溯的解析反演 → 离散假设空间上的贝叶斯 MAP），仅 **Schema** 保持——"由下游观测反推上游源事件时刻"的 F-线程逆问题图式（观测 → 演化律 → 源定位的三段逆推在抽象关系层逐段对应，对象映射非平凡）。答案取 SPEC L4 约定的多段式（建模选择的产物 + 数值），防蒙对。

### 【题面 + 解答】

**source（= L3-F-MU01 target，环境工程）**：题面同上（河道日终存量 409.7/334.2/285.9 kg 回溯泄漏日）。解答：差分消固定点 ρ≈0.80、x*≈200，对数回溯 n₁ = **6**。

**target（基因组流行病学/医院感染溯源）**：某院内感染暴发调查中，患者 P 的病原分离株相对本地参考株积累了 11 个 SNP。该病原的分子钟为泊松过程：突变以恒定速率 λ = 0.8 SNP/周 随机积累（SNP 数服从均值 λt 的泊松分布）。流行病学记录显示 P 只有 4 次可能的暴露事件，分别发生在采样前 6、9、12、15 周；按各次暴露的接触时长，调查组给定先验权重 1 : 2 : 2 : 1。问：(a) 最可能（最大后验）的暴露时刻是采样前多少周？(b) 该时刻的后验概率是多少（保留 2 位小数）？答案格式"周数;概率"。

**解答**：
1. 建模选择一（观测噪声）：SNP 计数是泊松随机变量，不能当确定量反解 t——必须对每个候选 t 算似然 P(K=11 | λt) = e^{−λt}(λt)¹¹/11!；
2. 建模选择二（先验）：4 个候选非等概，须乘先验权重 1:2:2:1；
3. 逐假设计算（μ = λt）：t=6 → μ=4.8，似然 0.00643；t=9 → μ=7.2，似然 0.05042；t=12 → μ=9.6，似然 0.10829；t=15 → μ=12.0，似然 0.11437；
4. 加权归一化：未归一化后验 ∝ {0.0064, 0.1008, **0.2166**, 0.1144}，归一化得 {0.015, 0.230, **0.494**, 0.261}；
5. MAP = 采样前 **12 周**，后验 **0.49**。

答案：**"12;0.49"**（string；周数精确匹配，概率 ±0.01）

**两条典型错误路径（多段式答案的区分力）**：
- 矩估计捷径：t̂ = k/λ = 11/0.8 = 13.75 周 → 取最近候选报 **15 周**（把随机计数当确定量反解，正是种子 Method 的残影）；
- 忘掉先验：仅比似然，t=15 的似然 0.1144 > t=12 的 0.1083，同样报 **15 周**。
  两条捷径都落在 15，与真值 12 干净分离；(b) 段后验概率进一步要求完整归一化，无法蒙对。

**lure（同域异图式，L4 约定）**：同一暴发调查的测序质控题——某关键位点真实变异等位基因频率 5%，测序深度 100×，生信流程要求 ≥3 条支持 reads 才报出变异。问该位点变异被检出的概率（百分数，保留 1 位小数）。【解答】X~Bin(100, 0.05)，P(X≥3) = 1 − P(0) − P(1) − P(2) = **88.2%**。
- 表面相似：同一个病原测序场景，同一批词汇（SNP/变异、reads、检出、概率），同样在数离散计数。
- 结构不同：这是**正向**的二项检出/灵敏度计算（E-图式：信号计数须过报出阈值），没有源事件假设空间、没有反演；照搬其"算检出概率"的算子对暴露溯源无从下手，反而诱导把"11 个 SNP"塞进二项检出框架。

### 【验证】

python3（scratchpad/verify_mu.py）：精确计算 4 个泊松似然与加权后验 {0.0147, 0.2301, 0.4942, 0.2610}，MAP=12、后验 0.4942→0.49 ✓；两条错误路径（仅似然 MAP、矩估计最近邻）均落在 15 ✓ 与真值可区分；lure 二项检出 P=0.8817→88.2% ✓。断言全部通过。

冷启动自评：泊松 MAP 本身不难，但"是否当确定量反解、是否用先验、能否给出归一化后验"三处建模选择叠加，估计 target-only 全对（两段都对）率 30–55%。

## 方法小结（构造体验）

1. **算子是"可控翻转开关"**：T-couple 精确地只动 Model（加固定点 / 破坏独立性），Schema 与线程自动保持，L3 的"照搬必错"探针不需要另行设计——它就是被算子废掉的那条种子解法本身，lure 也随手可得（= 未施 T-couple 的退化版）。
2. **链式变异天然产出难度梯度**：L2-F-05 → L3-F-MU01 → L4-F-MU03 是同一 F-图式（源事件回溯）上 Model/Method 被逐步剥离的过程，恰好构成半条迁移链，且每一级的负迁移探针都指向上一级的解法残影（矩估计 = 确定性反解的残影）。
