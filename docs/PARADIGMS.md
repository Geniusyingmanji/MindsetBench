# 数学模型之外的图式范式：调研综合

背景：现有 85 题的认知图式几乎全属同一范式——"把情境形式化为定量数学模型后求解"（守恒量、混合分布、信噪比、期望值、线性联立、依赖图皆是）。本文综合四路文献调研（认知科学、工程/系统传统、AI 推理范式、人文社科），给出数学模型之外的可迁移图式范式分类，作为后续任务拓展的地图。四份原始调研报告的出处均已核实（Gentner/Cheng-Holyoak/Talmy/Johnson-Laird、TRIZ/Senge/Alexander/Ashby、Pearl/Forbus/Walton/CBR、法律/叙事/SCT/谬误等）。

## 一、总分类：九个范式

判分方式栏说明可迁移图式如何落成机器可判题——这是全部范式入选的硬门槛。

### P1 定量数学建模（现状）
- 图式载体：量之间的函数关系；解 = 数值。
- 现有 7 线程全部在此。保留为基线范式。

### P2 符号/逻辑演算
- 图式载体：证明与判定的结构模板——鸽笼原理、极端原理、不变量/单变量、对称性论证、双计数、归谬、分类讨论；约束满足（变量-域-约束、传播、回溯）；缺省推理（默认规则+例外覆盖+优先级消解，结论可被新信息撤销——方程体系无对应物）。
- 与 P1 的分界：产出是"必然存在/不可能/真值"，不是数值；数字只作容器计数出现。
- 判分：求解器可验证（SAT/程序枚举）；三值判定（必然/必然否/不确定）。
- 与现有题库关系：B 线程的不变量题其实已经骑在 P1/P2 边界上——把"求最小残留量"改问"能否到达"，就从 P1 滑进 P2。
- 空位：逻辑谜题类已拥挤（ZebraLogic、SATBench、LogicBench），但"跨域迁移式命题"没人做；缺省推理中等空位（BoardgameQA、DeFAb）。

### P3 定性因果/系统结构（三路调研独立收敛，最强候选）
- 图式载体（三个来源恰好互补）：
  - 因果系统范畴（Rottman/Gentner/Goldwater 2012）：正反馈、负反馈、共因、共果、因果链——实验证明专家按因果结构跨学科归类现象、新手按学科归类，这就是我们 bench 想测的能力本身；
  - 系统基模（Senge）：舍本逐末、成长上限、公地悲剧、饮鸩止渴、恶性竞争升级等约 10 个封闭标签，每个 = 固定的反馈回路拓扑，系统动力学界刻意造的"免数学迁移接口"；
  - 因果之梯（Pearl）：关联/干预/反事实三层区分、混杂 vs 对撞、d-分离、该不该控制某变量——纯图结构判断，与数值估计可分离；
  - 定性推理（Forbus/Kuipers）：+/−/0 符号量、单调性链传播、数量级估计——LLM 时代该方向评测几乎空白（QuaRel/QuaRTz 停在 2019）；
  - 力动态（Talmy）：阻挡/放行/助推/压服等十余个定性力构型，天然的归类题答案空间。
- 判分：封闭标签集归类 + 回路/结构映射对齐；单调链逐量符号判分；d-分离程序可验证。
- 空位：高。且与 EvoCom 的 mindset 叙事最贴（"识别情境的因果拓扑"就是一种 mindset）。

### P4 规则/规范推理
- 图式载体：许可/义务图式（Cheng & Holyoak 1985 的道义推理，Wason 卡片任务的内容效应来源）；法律三件套——类推适用、区分（指出破坏先例核心关系的差异）、举轻以明重（a fortiori，偏序支配下的单调推理）；文义 vs 目的解释的工具箱分歧。
- 与 P1 的分界：判准是"关系相关性/规则语义"，不是数值；违规检测的答案结构（必须核查哪几项）唯一。
- 判分：违规检测选择题；类推/区分/举重明轻三选一 + 理由选项；a fortiori 偏序程序可判。
- 空位：高（LegalBench 在法律域内测，跨域迁移式没人做）。天然玩法：在虚构规范体系（火星站章程、游戏规则）里考，彻底规避语料污染。

### P5 操作/发明模式
- 图式载体：TRIZ 40 发明原理（分割、嵌套、事先反作用、变害为利、中介物……源自约 20 万专利分析，同一原理在互不通气的行业被反复独立重新发明）+ 4 分离原理（时间/空间/整体部分/条件）；BioTRIZ（生物与工程解同类矛盾仅 12% 重叠——迁移源分布本身可作题目变量）；Alexander→GoF 的"情境+力的冲突+解法结构"元格式。
- 与 P1 的分界：模式是可命名的结构操作（"分割""预先反作用"），完全非数学。
- 判分：原理编号是封闭离散标签；"哪个方案与源域解共享同一原理"四选一；力-解三元组映射对齐。
- 空位：高。独特价值：BioTRIZ 支持"迁移边界/负迁移"题（生物尺度机制放大到工程尺度失效），这是所有 mindset benchmark 都缺的维度。

### P6 案例/角色映射
- 图式载体：CBR 四步循环（retrieve-reuse-revise-retain）；判例推理的 factor 表示与"区分"操作（HYPO/CATO）；历史类比的角色系统映射（Spellman & Holyoak 1992：锚定映射下其余对应被一致性约束强制唯一）+ 类比压力测试（Neustadt-May 的 Likenesses/Differences 清单 →"哪条差异使推荐行动失效"）；诊断推理的 illness script（诱因-机制-表现三槽位）与 SCT 格式（新信息使假设可能性 ↑↑/↑/不变/↓/↓↓，心理测量学成熟且已跨专业迁移验证）。
- 判分：锚定映射下的强制对应；唯一"结构性差异"选择；SCT 方向判定（用设计好的因果结构保证方向唯一，规避专家分布判分争议）。
- 空位：高（CBR"区分"操作无 LLM benchmark；SCT 整体搬出医学域无人做过）。

### P7 论证/谬误图式
- 图式载体：Walton 60+ 论证图式，每个配一组 critical questions——CQ 清单在医疗、法庭、科技政策中逐字通用，天然自带跨域复用属性；非形式谬误 13–20 类结构定义（稻草人=曲解+攻击曲解版）。LOGICCLIMATE 已实证：谬误图式从教科书例句迁移到真实新闻域后所有模型性能显著下降——跨域迁移难度的直接证据。
- 判分："哪个 CQ 最能削弱该论证"选择题；跨域谬误结构同构对识别（比单纯分类更贴图式迁移主题）。
- 空位：中高（MAFALDA 等做域内分类，跨域同构识别没人做）。

### P8 策略/博弈机制识别
- 图式载体：承诺（烧船=删除自己选项反而获益）、可信威胁、信号与信号成本、筛选/逆向选择、道德风险、激励相容、逆向归纳、聚点、公地悲剧/囚徒困境的结构识别；规划图式（手段-目的分析、爬山陷阱——最优解必须包含表面倒退的一步）；Ostrom 八设计原则的缺失诊断。
- 与 P1 的分界：把情境映射到机制结构类，映射对了结论定性确定，无需算均衡数值。
- 判分：机制类型封闭标签；"哪一步是必要的倒退步"可用规划验证器判；单因失效场景的原则诊断四选一。
- 与现有题库关系：D 线程（止损/探索利用）已是本范式的期望值化身——本范式是它的"去数值版"扩展。
- 空位：机制识别子类高（GTBench/TMGBench 测对弈胜负，不测结构识别）。

### P9 叙事/脚本图式
- 图式载体：Propp 31 功能与 7 角色（ProppLearner 证明可机器归纳，F1≈0.70）、故事语法树、英雄之旅；跨介质结构同构（民间故事的"加害/缺失/伪英雄"映射到商业史新闻）。
- 判分：功能映射多选题（干扰项 = 表面相似但功能不同的事件）。
- 空位：高但判分边界最脆（标注一致性问题），建议作为探索档而非主力。

另有一类跨范式的"评价框架切换"（伦理四框架、解释方法之争）：直接问"哪个对"会退化为测文化共识，必须收窄为框架归属判定与框架内条件推断（"若采用义务论且以 X 为不可违规则，结论必然是什么"）——可作为 P4/P7 的进阶题型而非独立范式。

## 三、对 bench 设计的五点结论

1. 难度轴通用：L0–L4 的五成分分解（Surface/Domain/Model/Method/Schema）与范式无关，非数学范式直接沿用——变的只是"Model"一栏的内容（从方程变成回路拓扑/规则结构/原理编号/角色系统）。
2. 判分统一收敛为三种形式：封闭标签集归类（基模名/原理号/机制类/谬误类/力构型）、结构映射对齐（角色对应/回路映射/factor 差异）、方向或三值判定（SCT ↑↓/必然-不确定）。全部机器可判，与仅分数协议兼容。
3. 我们的独特位置得到确认：四路调研一致显示，现有 benchmark 全部在单一域内测单一范式，"源域教图式→远域考迁移"（Gick & Holyoak 双源归纳范式的评测化）没有成型工作——多范式 × 迁移距离双轴是全场空白。
4. 新增两个考察维度（现有 mindset benchmark 普遍缺失）：迁移边界识别（BioTRIZ 的尺度失效、历史类比的致命差异、瑞士奶酪的适用边界——即"知道图式何时不适用"）；推理方向区分（FTA 演绎回溯 vs ETA 归纳前推）。这两个维度天然是 lure 设计的升级版。
5. 判分红线：伦理/历史/叙事类严禁直接问"哪个对/哪个类比好"（会退化为测共识），必须收窄为框架归属、失效条件识别、功能映射这类有唯一结构答案的判别任务；高频历史案例（慕尼黑、烧船）与 TRIZ 经典案例语料污染重，出题须换皮到虚构或冷门载体。

## 四、建议的第一批新线程（对应 mindset.md 4.4 的 A–G 延续命名）

- 线程 H 因果拓扑（P3）：正/负反馈、共因/共果、基模归类——源域给一个负反馈现象及回路分析，远域四选一找同构 + 回路映射对齐。
- 线程 I 规范推理（P4）：许可/义务违规检测 + 虚构规范体系内的类推-区分-举重明轻。
- 线程 J 发明原理（P5）：TRIZ 矛盾-原理迁移 + BioTRIZ 迁移边界陷阱题。
- 线程 K 案例区分（P6）：factor 化先例 + 区分操作 + 跨域 SCT。
每线程先各造 4–6 题 pilot（L1–L4 各档），沿用多跳链纪律（去脚手架、照搬探针、计算量持平），并与现有 P1 题目做"同图式双范式"对照——同一个反馈结构分别用数学题（P1）和归类题（P3）考，直接测范式是否影响迁移梯度。
