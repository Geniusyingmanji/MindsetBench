# Far case 通俗说明

本页不复述完整题面，而是帮助读者快速理解：两道表面上不相干的题，究竟共享了什么 mindset。
每个案例只保留四件事：源域与目标域、直觉、最容易犯的错误、标准答案。完整字段、诱饵和 verifier 以
[`data/v1/`](../data/v1/) 中的 YAML 为准。

> 当前状态：下面这些 case 的跨域距离较大，但 GPT-5.6-sol 已能在 target-only 条件下稳定完成，因此目前都属于
> `sanity`，用于展示设计思路和回归测试，不作为“模型很难”的证据。

## 一眼看懂

| case | 源域 → 目标域 | 要迁移的 mindset |
| --- | --- | --- |
| 1 | 历史文献 → 手术排期 | 多个说法共用一个上游时，只算一份独立证据 |
| 2 | 食品污染溯源 → 雪豹路线 | “本应出现却没有出现”也能排除候选 |
| 3 | 鸟类觅食 → 求职投稿 | 探索是否值得，取决于之后还有没有时间利用结果 |
| 4 | 云接口停用 → 工会罢工 | 可信承诺来自事后不能轻易反悔 |
| 5 | 淋浴调温 → 高速车队 | 反馈有延迟时，反应过猛会来回振荡并逐级放大 |
| 6 | 门店差评榜 → 校招笔试 | 从很多人中挑出的最高分，通常混有向上的运气 |
| 7 | 抗议扩散 → 长梁支柱 | 级联取决于薄弱点如何分布，不取决于平均值或总量 |
| 8 | 黑板操作 → 舞蹈队形 | 先找所有操作都不改变的量，再判断目标能否达到 |
| 9 | 医院样本 → 恒星星表 | 筛选后的数据可能出现总体中不存在的关系 |
| 10 | 动物体型 → 冷库造价 | 长度、面积、体积按不同速度增长，单位成本不会等比例不变 |
| 11 | 三色探针 → 法院查档 | 主动调查要优化整棵决策树，而不是只看第一步 |
| 12 | 共源告警 → 专家公开表态 | 共享信息产生的多个判断不能当成独立证据连乘 |

## 1. 多位医生都同意，为什么还不算三份证据？

源域 → 目标域：地方志年代考订 → 不可逆手术排期（`FAR-INDEP-L3-01`）。

史料题里，六本书写着同一个年份，不代表有六份证据；如果五本都抄自同一本，它们实际上只有一个源头。
医院题把“抄书”藏进时间线：A、B、D 签字时还看不到 MRI 原片，只可能依据同一份文字报告。C 后来亲自看过原片，
主刀 E 虽然也看过，但按规程不能计入。

- 容易掉坑：直接数同意的医生人数。
- 正确思路：先问每个人签字前实际接触了什么一手证据，再按独立源头计数。
- 答案：当天只有 R 和 C 两份可计入的独立评估，不能排期；让 A 看原片后重签，或请外院专家独立看片，均可单独补足第三份。

这类 mindset 也适用于新闻转载、专家投票、模型 ensemble 和多个读取同一快照的 CI 检查。

## 2. 没拍到雪豹，为什么也是一条信息？

源域 → 目标域：食品污染供应商排查 → 保护区动物路线重建（`FAR-NEG-L4-01`）。

相机 A、C、F 在 06:00、06:50、08:00 拍到了雪豹。只看这些照片，会有不止一条路线说得通。
但 D 相机整晨正常工作却没有拍到它，因此任何经过 D 的路线都应被排除；E 相机坏了，没拍到就没有排除作用。

- 容易掉坑：只连接“拍到过”的地点，然后选择最短路线。
- 正确思路：正常设备的沉默是负证据，故障设备的沉默不是。
- 答案：唯一相容路线是 `A>C>F`，而不是经过 D 的更短候选路线。

关键不是笼统地说“缺失也是证据”，而是先确认：如果候选为真，这个信号是否本来就应该被可靠地观察到。

## 3. 为什么同一篇论文，剩四个月和剩六个月要选不同投稿策略？

源域 → 目标域：越冬鸟类试探新觅食地 → 求职截止前投稿（`FAR-HORIZON-L4-01`）。

期刊 B 两个月必录用，成果分 12；会议 A 三个月出结果，40% 概率录用，成果分 25。A 被拒后可以改投 B，
但 B 还要再审两个月。

- 容易掉坑：看到 A 的潜在收益更高，就认为总该先试 A。
- 正确思路：A 的试探价值来自“失败后仍有时间回到 B”这一退路。
- 答案：剩 4 个月应直接投 B；剩 6 个月应先投 A；至少剩 5 个月，先投 A 才划算。

它与觅食题共享的是“探索后的利用窗口”，但目标题已经从每天累积收益改成了带截止日期的一次性结果。

## 4. 为什么公开投票不一定让罢工威胁可信？

源域 → 目标域：云服务接口停用承诺 → 劳资谈判中的罢工威胁（`FAR-COMMIT-L4-01`）。

工会被拒后若罢工，成员损失 2；若不罢工，损失 0。即使工会提前公开投票、召开记者会，到了真正被拒绝的时刻，
它仍然更愿意不罢工，所以威胁不可信。

- 容易掉坑：把强硬措辞、公开仪式或准备了资金当成可信度。
- 正确思路：跳到对方已经拒绝之后，重新比较承诺人兑现和反悔的收益。
- 答案：只有与外部基金签不可撤销合同、规定“不罢工就损失 3”，能让罢工比反悔更划算；其余措施都没有真正改变工会事后的选择。

可信承诺的核心不是“现在有多认真”，而是“以后想反悔时还能不能反悔”。

## 5. 为什么司机反应越快，车队反而可能越危险？

源域 → 目标域：老式淋浴调温 → 五辆车的延迟跟驰（`FAR-DELAY-L4-01`）。

后车不是根据此刻的车速差调整，而是根据一秒前看到的差值调整。如果司机每次都把旧差值完整补足，真实情况可能早已变化，
于是车速会在过快和过慢之间来回摆动；前一辆的摆动又成为后一辆的输入，误差会沿车队放大。

- 容易掉坑：认为反应系数越大、越快追上前车就越安全。
- 正确思路：有延迟时要降低增益，并检查扰动沿多个环节是放大还是衰减。
- 答案：候选系数中只有 `0.3` 满足要求，第五辆车的最大减速约为 `3.1 km/h`；`0.6` 会放大到约 `27.9 km/h`。

这里迁移的不是某个温控公式，而是“延迟反馈下，足额纠偏可能过度”的系统直觉。

## 6. 笔试答对 19 题的人，下次为什么只预测 17.6 题？

源域 → 目标域：连锁门店差评榜首 → 校园招聘最高分者（`FAR-EXTREME-L4-01`）。

公司让 15 人做同一份 20 题笔试，并录用最高分者。被录用者这次答对 19 题，但一次考试既反映能力，也包含运气；
而且公司特意从 15 人中挑了最高的那个，向上的偶然波动更容易被选中。

- 容易掉坑：把 19 分直接当成稳定能力，预测下次仍为 19 分。
- 正确思路：根据不同真实能力产生 19 分的可能性反推能力，再预测下一次表现。
- 答案：估计真实答对率约为 0.878，所以下一次同难度 20 题的期望是 `17.6` 题。

这就是常见的“冠军回落”：最高观测值通常比冠军的稳定水平更极端。

## 7. 总承载力一样，为什么一种桥全倒、一种只坏一根？

源域 → 目标域：人群抗议的门槛扩散 → 长梁支柱的连续失效（`FAR-CASCADE-L4-01`）。

两种设计的总承载力完全相同。第 3 根柱被撞毁后，它的荷载会转移给最近的左右支柱。
设计 P 的承载力分布很平均，但邻柱只多出 4 的余量，接到 5 的新增荷载就会继续倒下；新倒下的柱又把更大荷载传给下一根。
设计 Q 把高余量柱恰好放在撞击点两侧，一次就把额外荷载吸收了。

- 容易掉坑：只比较总承载力和总荷载。
- 正确思路：逐轮观察压力传到哪里，以及当地有没有能截断传播的“大余量”节点。
- 答案：P 最终失去 `8` 根柱，Q 只失去最初的 `1` 根。

抗议、挤兑、技术扩散和结构失效都可能共享这种“跨过门槛后继续推动邻居”的级联骨架。

## 8. 舞者一直轮转，为什么仍有一半队形永远排不出来？

源域 → 目标域：黑板数字操作 → 舞蹈队形编排（`FAR-INVAR-L3-01`）。

8 名舞者排成一列，每次只能让相邻三人循环换位。三人轮转等价于做两次两人交换，所以无论做多少次，
排列所属的奇偶类别都不会改变。

- 容易掉坑：认为操作次数不受限，迟早能凑出任何队形。
- 正确思路：搜索以前先找出每个合法动作都保持不变的性质。
- 答案：只交换 1、2 的队形不可达；同时交换 1、2 与 3、4 的队形可达，最少 `2` 次走位。

verifier 穷举了 8 人的 40320 个排列，只有 20160 个——恰好一半——能够从初始队形到达。

## 9. 为什么星表里“越远的星越亮”，却不能说明远处的星本来更亮？

源域 → 目标域：住院样本中的疾病关联 → 恒星星表的亮度与距离（`FAR-BERK-L4-01`）。

设想全部恒星里，距离和真实亮度原本互不相关。但星表有一个收录门槛：看起来不够亮的星不会被记录。
近处的暗星还能被看到，远处的暗星却会消失在样本中；因此，星表里的远处恒星只剩下真实亮度较高的那些。

- 容易掉坑：把星表里的关系直接当作所有恒星的关系。
- 正确思路：先问数据如何进入样本，再判断观察到的关系是否由筛选规则制造。
- 答案：全部恒星中距离与亮度无关；星表内部呈正相关；不能据此推断远处恒星本身普遍更亮。

同样的问题会出现在医院病例、面试候选人、课程评论和只记录成功项目的数据集中。

## 10. 为什么冷库边长翻倍，每立方米造价反而减半？

源域 → 目标域：动物体型与散热 → 冷库围护结构造价（`FAR-SCALE-L4-01`）。

冷库围护结构按表面积收费，储存能力却按体积计算。边长翻倍时，表面积变成 4 倍，容积变成 8 倍，
所以摊到每立方米上的围护成本只有原来的一半。

- 容易掉坑：认为同样规格的设施，无论大小，单位容量造价都一样。
- 正确思路：分清成本跟面积走，收益或容量跟体积走。
- 答案：边长 10 米的小库每立方米围护成本为 240 元；边长 20 米的整体大库为 `120` 元。

如果大库被隔成八个都要完整六面围护的小间，面积优势就会消失；这也是该题诱饵与目标结构不同的地方。

## 11. 第一份判例把候选分得最平均，为什么还不是最佳选择？

源域 → 目标域：三色诊断探针 → 行政法院的定向判例调阅（`FAR-LATENT-PRECEDENT-L4-01`）。

法院可能采用六套内部判准。调阅一份封存判例后，会看到“准许、驳回、发回”之一，然后可以根据结果决定是否以及调阅哪一份第二判例。
不同卷宗的费用不同。

Y 卷第一步能把六套判准漂亮地分成 2/2/2，看起来信息量最好；但它本身费用高，完成所有后续分支的最坏费用是 8。
X 卷的第一步没那么整齐，却有一个分支能立即结束，另两个分支分别用便宜的 W、V 区分，最坏费用只有 7。

- 容易掉坑：只比较第一步把候选分得是否平均。
- 正确思路：为每个首选查询展开完整的后续分支，再比较最坏路径总成本。
- 答案：先查 X；准许时停止，驳回时查 W，发回时查 V；最坏费用为 `7`。

这类题更接近 active learning：目标不是被动回答，而是在有限预算内决定下一步去获取什么信息。

## 12. 两位专家都支持，为什么不能把可信度简单平方？

源域 → 目标域：工业控制台的重复告警 → 历史建筑真伪评议（`FAR-LATENT-SOCIAL-CORRELATED-L4-02`）。

两位研究员都看到同一份目录线索，再分别听取自己的私人证言，最后公开支持或反对“建筑是真迹”。
两人虽然是不同的人，但他们的判断共享同一个上游线索，所以两个公开支持并不独立。

- 容易掉坑：先算一位研究员支持的概率，再把它平方，仿佛两人各自看到了独立目录。
- 正确思路：共同目录只抽取一次；在同一个目录分支下，再分别考虑两人的私人证言和公开决定。
- 答案：前两项公开支持在给定真伪状态后仍不独立；加入第三位专家的独立材质检验及其表态后，真迹后验概率为 `0.9797`。

它比“两个屏幕复制同一个传感器”更远一步：公开表态不是原始线索的直接复制，而是共享线索、私人信息和决策规则共同压缩出的行为。

## 怎样判断一个 case 是否真的测到了迁移？

表面跨度大并不自动等于迁移题足够难。一个合格的候选题至少还应满足：

1. target-only 不能已经接近满分，否则没有观察正迁移的空间；
2. source 只能提供思维框架，不能直接提供目标计算表或答案模板；
3. lure 必须在目标领域里很自然，但其关键关系与目标不一致；
4. 错误应集中体现错误 mindset，而不是格式、歧义、截断或纯计算量不足；
5. `with-source` 应优于 `target-only`，同时优于 `with-lure`，才有较干净的迁移证据。
