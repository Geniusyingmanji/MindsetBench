# 跨学科类比 case 的四种构造方法

同一个目标（构造"源题→目标题"跨学科迁移对），四条不同的生成路径。每种方法各产出 3 个已验证 case（cases/methodAR、methodPair、methodMut、methodHist 的 .md/.jsonl，jsonl 带 "method" 字段），加上题库主体使用的图式先行法，共五种。

## 方法一：图式先行（schema-first）

题库主体 43 题的构造方式。先确定抽象认知图式（如"可行域被隐式约束切割"），再分别在两个学科实例化出源题和目标题。

- 流程：选图式 → 选学科对 → 双侧实例化 → 参数标定 → 验证。
- 优点：图式纯度最高，等级归属可控（想造 L3 就造 L3）；线程归属天然明确。
- 缺点：双侧题面都是新造的，"学科真实感"依赖构造者的领域知识；lure 需要另行设计。
- 适合：按线程×等级系统性铺满题库矩阵。

## 方法二：AR 管线（AR-pipeline）

复刻 Analogical Reasoning 论文的两步法，且保留全部中间产物：源题 → 显式抽取对象集与关系集 → 按关系集检索宿主学科、生成对象映射表 → 实例化目标题。

- 产出：L2-A-AR1（语言学音系 ↔ 功能和声）、L3-B-AR2（社会网络阈值传播 ↔ 建筑连锁倒塌）、L4-D-AR3（运动生理临界功率 ↔ 供暖热惰性）。
- 体验：对象/关系一旦显式化，跨域检索接近机械填表，L2 同构性可逐条勾选；lure 设计变成"保 Surface、换掉最核心一条关系"的反向实例化，几乎免费。卡点在 L3/L4 要反复试"丢哪条关系"，且数值标定仍靠手工迭代。
- 独特价值：中间产物（对象映射表、共享关系子集）就是 mapping 字段的直接来源，标注质量最高；这条管线同时就是线程同一性验证器的生成方向。

## 方法三：真题配对（corpus-pairing）

不造题，找题：从两个学科的教材/竞赛中找出本来就存在的同构经典题型配成对，再重设参数防污染。

- 产出：L2-F-CP01（牛顿冷却尸温断案 ↔ 利率均值回复）、L3-B-CP01（M/M/1 ↔ 有限缓冲丢包）、L3-G-CP01（并联冗余 ↔ X 连锁遗传）。
- 体验：同构论证近乎免费（教材题结构骨架干净），lure 天然存在于"教材里紧挨着的另一节"（无限 vs 有限缓冲、常染色体 vs X 连锁）。卡点是 L3 检索空间小——要求两学科恰好各收录了同一数学结构的不同变体；且经典题型语料密度高，冷启动偏易，需把问句问到易错步来拉回难度净空。
- 独特价值：生态效度最高——两侧都是"该学科学生真的会做"的题，最能反驳"人造题对"的质疑。

## 方法四：变换算子（mutation）

从已验证的种子题出发，施加显式变换算子推导新题，保留推导链：T-reskin（换表面/领域）、T-couple（独立改相依/加隐藏约束）、T-noise（确定改随机/加观测误差）、T-invert（正问改逆问）。

- 产出：L3-F-MU01（L2-F-05 → reskin+couple：金融→环境工程，离散仿射递推）、L3-E-MU02（L2-E-04 → reskin+couple：共模噪声破坏条件独立）、L4-F-MU03（链式变异 → noise+reskin：泊松计数 MAP 溯源）。
- 体验：负迁移探针"免费"——T-couple 精确废掉的那条种子解法本身就是照搬错误答案，退化版顺手即成 lure，L3 三件套（题、探针、lure）一次成型；链式变异天然产出同图式难度梯度。主要成本在数值再校准（每题 1–2 轮调参保证照搬答案与真值干净分离）。
- 独特价值：可规模化——算子库固定后可半自动批量推导，且"每级错误路径是上一级解法的残影"使其成为迁移链的自然生成器。

## 方法五：科学史迁移（history-mining）

从科学史上真实发生的跨学科概念迁移出发落成题对：源题在思想原生域，目标题在被迁移域。

- 产出：L2-D-HI01（冶金退火 → 模拟退火排产）、L3-A-HI02（卢瑟福泊松计数 → Erlang B 话务）、L4-F-HI03（布朗运动/佩兰 → Black-Scholes 隐含波动率）。
- 体验：等级归属与 mapping.varied 几乎免费——文献写明了迁移时哪些结构保持、哪些被适配（Kirkpatrick 只换语义→L2，Erlang 发明截断归一化→L3，BS 全重造只留随机游走图式→L4）；lure 有历史上真实存在过的错误直觉作原型。
- 风险：著名迁移案例训练语料密度高，模型可能早已内化该类比，迁移增益被稀释——这三题的 target-only 基线应优先实测。
- 独特价值：外部效度论证——"这个图式的跨域迁移在人类科学史上真实发生过且有产出"，是对 L3/L4 题"迁移有意义"的最强背书。

## 方法选择建议

| 需求 | 首选方法 |
| --- | --- |
| 系统铺满线程×等级矩阵 | 图式先行 |
| mapping 标注质量 / 与 SMT 验证器对齐 | AR 管线 |
| 生态效度、答复"题对是人造的"质疑 | 真题配对 |
| 批量扩产、构造迁移链、免费负迁移探针 | 变换算子 |
| 外部效度、L4 远类比的意义背书 | 科学史迁移 |

污染风险从低到高：图式先行 ≈ 变换算子 < AR 管线 < 真题配对 < 科学史迁移（后两者用重设参数与改问法补偿，且应实测冷启动基线）。
